# AI Agent 助教技能培訓工作坊執行摘要

> 計畫名稱：智慧雨林產業創生人才育成計畫  
> 副標：從工具安裝、檔案管理到問題排除

## 計畫定位

本工作坊是一場半日的 AI Agent 實作培訓，對象以教師或各單位推薦的助教為優先；如有名額，也歡迎具備基本電腦與 AI 使用經驗的行政／辦事同仁及其他有興趣者參與。預計約 30 人，參與者以自己的筆記型電腦獨立操作。

本場不是教材設計、命題或評量設計課程。它的核心任務是培養能支援教師使用 AI Agent 與簡易 vibe coding 工具的第一線人員，降低非工程背景教師在本機安裝、檔案管理、執行、測試與基本問題排除上的負擔。

## 核心目標

本場以 ChatGPT Codex 為示範工具，但重點不在學習單一平台，而是建立可轉用到其他 AI Agent 的工作方法：說清楚目標、情境、限制與完成標準；讓 AI 協助產生工具；自行找到並執行產出；測試與判讀結果；再逐步修正。

參與者在一個下午內，將練習：

1. 分辨 Chatbot 與 AI Agent 的差異、適用範圍與限制。
2. 安裝、驗證與初步排除 VS Code、Python、Node.js 等本機環境問題。
3. 建立專案資料夾，辨識來源檔、產出檔與執行位置。
4. 透過 vibe coding 產生一個簡單的靜態 HTML 小工具，並在本機開啟、測試、判斷問題與提出修正需求。
5. 演練未來協助教師或教學助理時常見的技術問題處置方式。

## 下午重點流程

|---|---|
| 13:00–13:25 | 認識 AI Agent 與助教支援角色。 |

| 14:20–14:50 | 開啟練習專案並確認執行流程。 |

| 17:20–17:30 | 回顧、提問與課程收束。 |

## 執行原則與預期價值

- 練習以主辦單位提供的資料與專案進行；不使用學生個資、成績、未公開教材或其他敏感資料。
- AI 產出是草稿或輔助結果；工具是否能使用、結果是否正確，仍須由人員實際測試與確認。
- 小工具只維持本機可開啟、可檢查的最小範圍，不延伸至帳號、資料庫、即時同步或正式部署。

透過這項培訓，可為未來工作坊建立助教人才，也可讓參與三場教師工作坊的教師先替實驗室或教學助理完成前置技術訓練。目標是讓教師能專注於教學與專業工作，而由具備共同技術基礎的助教或行政人員協助處理環境、檔案、執行與初步測試問題。
