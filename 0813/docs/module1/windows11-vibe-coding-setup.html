Windows 11 Vibe Coding 與 AI Agent 環境建置

本模組聚焦在 Windows 11 筆電上的 Vibe Coding 與 AI Agent 工作環境建置。先安裝 ChatGPT 桌面 app，再用一鍵安裝腳本準備開發工具；最後以 Chat、ChatGPT Work 與 Codex 的正確工作介面完成幾個小型驗證任務。

學習目標 (Learning Objectives)

完成本模組後，教師應能：

  • 在自己的 Windows 11 筆電上獨立啟動可運作的 Vibe Coding 與 AI Agent 工作環境。
  • 使用 ChatGPT 桌面 app 的 Chat、ChatGPT Work 與 Codex 工作介面，依任務選擇適合的入口。
  • 使用 VS Code 作為主要開發介面，搭配 Codex CLI 與 Codex 擴充套件進行程式生成、修改與檢查。
  • 使用 uv 與 npm 管理 Python 與 Node.js 的套件及專案環境。
  • 透過 GitHub CLI (gh) 以瀏覽器登入 GitHub，完成專案 clone、推送與 GitHub Pages 部署。
  • 依據 checklist 自行驗證環境，並排除常見安裝問題。

若一鍵安裝失敗，或教師的筆電受學校 IT 權限限制，可改用手動安裝。建議仍優先使用 winget 指令；若 winget 不可用，再從官方下載頁面安裝。

ChatGPT 桌面 app OpenAI：ChatGPT desktop app for Windows winget install --id 9PLM9XGG6VKS --source msstore，或從 Microsoft Store 安裝。安裝後開啟 app，使用 ChatGPT 帳號登入。

安裝方式二：透過 AI Agent Prompt 安裝（ChatGPT Work，完整存取權）

除了執行批次檔或手動安裝，也可以直接在 ChatGPT 桌面 app 中改用自然語言，讓 AI Agent 自行檢查筆電上缺少哪些工具、依序安裝並回報結果。

⚠️ 完整存取權（Full access）會讓 Agent 不經逐步核准就執行終端機指令，安裝流程結束後請切回先要求核准（Ask for approval）。

建議操作：

  • 開啟 ChatGPT 桌面 app，選擇 ChatGPT，再切換到 Work。
  • 在工作設定中把存取層級改成完整存取權（Full access）。
  • 貼上下列 prompt 並送出，全程留意輸出內容：
我使用的是 Windows 11 筆電，具備系統管理員權限，已安裝 App Installer (winget)。
請幫我檢查並安裝以下開發工具，若已安裝則略過，全部安裝完成後請執行版本檢查指令並回報結果：

1. VS Code（winget id: Microsoft.VisualStudioCode）
2. Git for Windows（winget id: Git.Git）
3. Node.js LTS + npm（winget id: OpenJS.NodeJS.LTS）
4. uv（winget id: astral-sh.uv）
5. GitHub CLI（winget id: GitHub.cli）
6. Codex CLI（先確認 Node.js 已安裝，再執行 npm install -g "@openai/codex"）
7. 以下 VS Code 擴充套件：
   - ms-python.python
   - ms-toolsai.jupyter
   - eamodio.gitlens
   - dbaeumer.vscode-eslint
   - openai.chatgpt

安裝規則：
- 每一項工具在安裝前先檢查是否已存在（例如執行「工具 --version」或「winget list --id ...」），已安裝就跳過，不要重複安裝。
- 使用 winget 安裝時加上 --source winget --exact（VS Code 擴充套件改用 code --install-extension）。
- 全部安裝完成後，開新的終端機視窗，依序執行下列指令並把結果貼給我：
  code --version
  git --version
  node --version
  npm --version
  uv --version
  gh --version
  codex --version
- 若任何一項安裝失敗，請停下來告訴我錯誤訊息，不要略過或用其他方式繞過。
- 不要安裝清單以外的軟體，也不要修改系統設定或使用者帳戶權限。

Agent 執行完成後，請比對輸出結果與上方「安裝的工具」表格，確認每個指令都能顯示版本號；若有工具檢查失敗，可回到「安裝方式一：手動下載與安裝必要工具」單獨修復。

安裝方式三：使用 module1-setup-windows.bat 一鍵安裝

優先使用本模組提供的 module1-setup-windows.bat。這個批次檔會檢查 winget，再依序安裝 VS Code、Git、Node.js LTS、uv、GitHub CLI、ChatGPT 桌面 app、Codex CLI 與常用 VS Code 擴充套件。腳本可重複執行；已安裝的項目會自動略過。

建議操作：

  • 下載 module1-setup-windows.bat，或將檔案放到容易找到的位置，例如 Downloads。
  • 以滑鼠雙擊執行，或在 PowerShell 執行：
& "$HOME\Downloads\module1-setup-windows.bat"
  • 若使用 Command Prompt，執行：
"%USERPROFILE%\Downloads\module1-setup-windows.bat"
  • 腳本結束後，關閉並重新開啟 PowerShell 或 Command Prompt，讓 PATH 設定生效。
  • 重新執行下列檢查指令，確認主要工具都能被系統找到：
code --version
git --version
node --version
npm --version
uv --version
gh --version
codex --version

若腳本顯示 winget not found，請先安裝或更新 Windows 的 App Installer，完成後再重新執行批次檔。

實作流程 (Hands-on Activities)

1. 設定 ChatGPT、Work 與 Codex

  • 開啟 ChatGPT 桌面 app 並登入。需要快速問答時選 Chat；要完成研究、文件或可審查的多步驟成果時，先選 ChatGPT，再切換到 Work；要處理課程 project、程式碼、指令與 diff 時，從產品選單選 Codex。
  • 在 Codex 先開啟這次課程唯一的 project 資料夾。傳送第一個任務前，選擇先要求核准（Ask for approval）；不要預設開啟完整存取權（Full access）。完成後檢查核准要求、diff 與輸出檔案。
  • 需要終端機工作流程時，再執行 codex 並以瀏覽器登入可使用 Codex 的 ChatGPT 帳號；同一帳號可同時用於 VS Code 的 Codex 擴充套件。
  • 若後續任務需要操作瀏覽器，讓 AI Agent 依任務需求自行安裝與設定對應工具即可；本模組不把瀏覽器自動化外掛列為預先安裝項目。
  • 執行 guided「Hello, AI Agent」任務 (請 Agent 建立一個 hello.txt)，確認 AI Agent 能接收指令、產生檔案並回報結果。

2. 連結 GitHub 與部署 GitHub Pages

  • 執行 gh auth login，全程以瀏覽器與一次性代碼登入，不需產生 SSH 金鑰或於終端機輸入密碼，並一次設定好 git 認證與提交身分 (user.name / user.email)。
  • 練習 gh repo clone 下載專案，以及用 gh repo create … --push 與 GitHub Pages 把靜態網站發佈成公開網址。

3. 四項驗證任務 (Verification Tasks)

任務 內容 驗證重點
Python 驗證 以 uv 建立專案並安裝 openpyxl、python-docx，讀取 Excel、整理資料並輸出新的 Excel 檔案 套件與檔案處理可運作
Word 驗證 讀取 Word 文件內容，並產生一份修改後的 Word 檔案 Office 文件處理可運作
JavaScript 驗證 以npx http-server 啟動簡單的 local web server，確認 client-side 與 server-side 程式正常執行 Node.js 與 local host 可運作
Codex 驗證 請 Codex 建立簡單文字檔、修改範例程式或整理指定資料 AI Agent 可讀寫工作區檔案並回報結果

Windows 11 Vibe Coding and AI Agent Environment Setup

This module prepares a Vibe Coding and AI Agent environment on a Windows 11 laptop. Install the ChatGPT desktop app first, then use the setup script for the developer tools. Finally, choose Chat, ChatGPT Work, or Codex for the appropriate verification task.

Learning Objectives

After this module, participants can:

  • Set up a working Vibe Coding and AI Agent environment on a Windows 11 laptop.
  • Choose Chat, ChatGPT Work, or Codex in the ChatGPT desktop app for the task at hand.
  • Use VS Code with Codex CLI and the Codex extension to create, edit, and review code.
  • Use uv and npm to manage Python and Node.js packages and project environments.
  • Use the GitHub CLI (gh) to sign in to GitHub through the browser, then clone, push, and deploy to GitHub Pages.
  • Use the checklist to verify the environment independently and troubleshoot common setup issues.

Install Method 2: Install via an AI Agent Prompt (ChatGPT Work, Full Access)

Instead of running the batch file or installing manually, you can also open the ChatGPT desktop app and use a natural-language prompt so the agent checks what is missing on the laptop, installs it, and reports back.

⚠️ Full access lets the agent run terminal commands without asking for approval on each step. Switch back to Ask for approval once the install is finished.

Suggested steps:

  • Open the ChatGPT desktop app, choose ChatGPT, then switch to Work.
  • In the task settings, change the access level to Full access.
  • Paste the prompt below and send it, and watch the output the whole time:
I'm on a Windows 11 laptop with administrator rights, and App Installer (winget) is already installed.
Please check and install the following developer tools, skipping anything already installed. After everything is installed, run the version-check commands and report the results back to me:

1. VS Code (winget id: Microsoft.VisualStudioCode)
2. Git for Windows (winget id: Git.Git)
3. Node.js LTS + npm (winget id: OpenJS.NodeJS.LTS)
4. uv (winget id: astral-sh.uv)
5. GitHub CLI (winget id: GitHub.cli)
6. Codex CLI (confirm Node.js is installed first, then run npm install -g "@openai/codex")
7. These VS Code extensions:
   - ms-python.python
   - ms-toolsai.jupyter
   - eamodio.gitlens
   - dbaeumer.vscode-eslint
   - openai.chatgpt

Rules:
- Before installing each tool, check whether it already exists (e.g. run "tool --version" or "winget list --id ..."); skip it if it's already installed, don't reinstall.
- When using winget, add --source winget --exact (for VS Code extensions, use code --install-extension instead).
- After everything is installed, open a new terminal window, run the following commands in order, and paste the results back to me:
  code --version
  git --version
  node --version
  npm --version
  uv --version
  gh --version
  codex --version
- If any install step fails, stop and tell me the error message; don't skip it or work around it another way.
- Don't install anything outside this list, and don't change system settings or user account permissions.

Once the agent finishes, compare its output against the Toolchain table above to confirm each command prints a version number. If a check fails, go back to "Install Method 1: Manual Download and Installation" to fix that tool individually.

Install Method 3: One-Click Setup with module1-setup-windows.bat

Start with the supplied module1-setup-windows.bat. It checks winget, then installs VS Code, Git, Node.js LTS, uv, GitHub CLI, the ChatGPT desktop app, Codex CLI, and common VS Code extensions. The script is safe to run again; installed items are skipped.

Suggested steps:

  • Download module1-setup-windows.bat, or move the file somewhere easy to find, such as Downloads.
  • Double-click to run it, or run it in PowerShell:
& "$HOME\Downloads\module1-setup-windows.bat"
  • If using Command Prompt, run:
"%USERPROFILE%\Downloads\module1-setup-windows.bat"
  • After the script finishes, close and reopen PowerShell or Command Prompt so the PATH changes take effect.
  • Run the following checks again to confirm the system can find each tool:
code --version

uv --version
gh --version

If the script prints winget not found, install or update Windows App Installer first, then run the batch file again.

Hands-on Activities

1. Set up ChatGPT Work and Codex

  • Open the ChatGPT desktop app and sign in. Use Chat for quick questions; select ChatGPT, then Work for a multi-step, reviewable outcome; select Codex for a course project, code, commands, and diffs.
  • In Codex, open only the intended course project folder. Before the first task, choose Ask for approval; do not enable Full access by default. Review approval requests, diffs, and output files.
  • For a terminal workflow, run codex and sign in through the browser with the same ChatGPT account. The VS Code Codex extension can use that account too.
  • If a later task needs browser automation, let the AI agent install and configure whatever tools it needs on its own; this module doesn't pre-install any browser automation add-ons.
  • Run the guided "Hello, AI Agent" task (ask the agent to create a hello.txt file) to confirm the AI agent can receive instructions, produce a file, and report back.

2. Connect GitHub and Deploy GitHub Pages

  • Run gh auth login and sign in entirely through the browser with a one-time code — no SSH keys or passwords typed into the terminal — which also sets up git credentials and your commit identity (user.name / user.email) in one step.
  • Practice cloning a project with gh repo clone, and use gh repo create … --push together with GitHub Pages to publish a static site to a public URL.

3. Four Verification Tasks

JavaScript check Start a simple local web server with npx http-server to confirm client-side and server-side code run correctly Confirms Node.js and the local host work
Codex check Ask Codex to create a simple text file, modify a sample script, or organize a specified dataset Confirms the AI agent can read and write workspace files and report results
