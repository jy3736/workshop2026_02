# AI Agent 教學應用工作坊（二）模組一設計規劃

## 從教材產生題組：PDF 題目／答案文件 → 選擇題題組

## 模組定位

`模組設計規劃.md` 的 M2、M3 是「第一階段：從教材產生題組」的通用版流程，假設學員素材可能是講義、簡報或教材片段。實務上，很多學員手上其實是**現成的 PDF 題目與答案文件**——歷屆考題、作業與解答、附答案的題庫講義。這種素材已經有明確的「正確答案」，任務性質與「從零開始出題」不同：**核心工作是忠實抽取＋格式轉換，而不是創作新題目**，最大風險也從「題目品質」轉為「答案是否還跟原始文件一致」。

本文件是**模組一**的獨立設計文件，針對「PDF 題目／答案文件 → 選擇題題組」這個具體情境，把 M2、M3 的通用流程換成更具體的步驟、任務卡與查核機制。若學員素材是原始教材而非現成題目，仍請使用 `模組設計規劳.md` 的通用版 M2／M3；兩者可在同一場次並行使用，依學員素材類型分流。

---

## 一、學習目標

完成本模組後，學員能夠：

1. 判斷手上的 PDF 題目／答案文件是否適合直接使用、需要前處理，或該換一份文件。
2. 請 AI Agent 精準「抽取」PDF 中的原始題目與答案，並在抽取階段就核對正確性，避免後續被錯誤或幻覺答案污染。
3. 將非選擇題格式（簡答、填空、計算、問答）的題目轉換為四選一選擇題，並設計出合理的錯誤選項（誘答選項）。
4. 依「干擾選項設計原則」檢核並修正 AI 產生的錯誤選項品質。
5. 產出一份與原始 PDF 答案一致、格式統一的選擇題題組檔案，可直接交給 vibe coding 階段（M4）使用。

---

## 二、模組範圍與適用情境

**適用**：教師手上有 PDF 格式的題目與答案（歷屆考題、作業與解答、附答案的題庫講義），希望轉成選擇題形式的自主練習題組。

**三種常見來源型態，難度由低到高**：

| 來源型態                 | 說明                                 | 本模組任務                                                         | 難度                   |
| ------------------------ | ------------------------------------ | ------------------------------------------------------------------ | ---------------------- |
| 已是選擇題＋答案         | PDF 本身就是四選一或其他形式的選擇題 | 只需抽取與格式化                                                   | 低                     |
| 簡答／填空／計算題＋答案 | 有明確標準答案，但非選擇題形式       | 需「新增選項」轉換為選擇題                                         | 中                     |
| 開放式問答／申論題       | 答案不唯一或需多步驟論述             | 不一定適合轉為單選題，需教師判斷是否跳過、簡化為概念題，或另行處理 | 高／可能超出本模組範圍 |

大多數 PDF 會混雜以上多種型態，模組流程會要求 AI 在抽取階段就標註每題屬於哪一種，方便後續分流處理。

## 三、與整體工作坊時間軸的對應

本模組取代 `模組設計規劃.md` 的 M2（13:10-14:00）與 M3（14:00-14:50），共 100 分鐘，拆解為六個步驟：

| 步驟 | 內容                                | 時長  | 對應時段 |
| ---- | ----------------------------------- | ----- | -------- |
| 0    | PDF 前處理檢查                      | 5 分  | M2       |
| 1    | 選定與確認處理範圍                  | 10 分 | M2       |
| 2    | 抽取任務：AI 逐題抽取原始題目與答案 | 20 分 | M2       |
| 3    | 抽取結果核對                        | 15 分 | M2       |
| 4    | 非選擇題轉選擇題：AI 生成錯誤選項   | 20 分 | M3       |
| 5    | 選擇題品質與答案一致性核對          | 20 分 | M3       |
| 6    | 彙整定稿為統一資料格式              | 10 分 | M3       |

步驟 0-3（45 分＋5 分緩衝）在原 M2 時段完成，步驟 4-6（50 分）在原 M3 時段完成，M2、M3 的保底標準與查核清單邏輯不變，只是內容換成 PDF 專屬版本。

## 四、步驟 0：PDF 前處理檢查（5 分）

流程一開始先過一次檢查表，避免處理到一半才發現文件不適用：

- [ ] **文字可選取嗎？** 能用滑鼠反白選取文字 → 可直接讓 AI 讀取文字。無法選取（純掃描圖片）→ 需確認 AI 工具是否具備圖像／視覺閱讀能力；不確定時先用 1-2 頁測試辨識準確度，或用 OCR 軟體先轉成文字，必要時人工重新謄打有問題的段落。
- [ ] **題目與答案能明確對應嗎？** 若答案另附於別頁（如答案卷），需確認題號、頁碼對得起來。
- [ ] **處理範圍已決定嗎？** 若題數遠超過本模組時間可處理的量（例如上百題），先選定一個子集（如 20-30 題），其餘留待會後用同一套任務卡自行處理。
- [ ] **是否有大量數學公式、圖表、圖片型選項？** 這類內容轉成純文字選擇題可行性較低，先標記，抽取時特別注意或直接跳過。
- [ ] **使用限制是否已確認？** 文件若非自己出版／自編，或屬未公開考題，需確認可在 AI 對話中使用，不涉及版權或保密疑慮。

## 五、步驟 1：選定與確認處理範圍（10 分）

- 從 PDF 中選定要處理的題號範圍或單元（呼應步驟 0 的範圍決定）。
- 快速瀏覽選定範圍，標記明顯屬於「開放式問答／申論題」的題目，初步決定是否納入本次轉換，或列為「不轉換」保留原樣。
- 確認題數：建議至少 10 題、以 15-20 題為佳，與 `模組設計規劃.md` M2 的題數建議一致。

---

## 六、步驟 2：抽取任務（20 分）——任務卡 1

這一步**只做忠實抄錄，不做任何加工**，目的是把「AI 有沒有看懂 PDF」與「要不要把題目轉成選擇題」這兩件事分開處理，避免抽取錯誤被一路帶進後面的轉換階段而不易察覺。

### 任務卡 1：PDF 逐題抽取任務卡

```
目標：請逐題抽取以下 PDF 中的題目與正確答案，整理成表格，不要摘要、不要改寫、不要自行解題。
情境：這份 PDF 是我實際使用的題目與答案（來源：＿＿＿），我要用抽取結果確認你有沒有
      看錯或漏看，再進行下一步轉換，所以這一步只需要「忠實抄錄」，不需要你判斷題目好不好。
限制：
  - 只處理第＿＿到＿＿題（或：只處理＿＿單元／頁碼範圍）。
  - 每一題請標注：原始題號、原始頁碼（若可辨識）、題目原文、原始答案原文、
    題型判斷（已是選擇題／簡答填空計算／開放式問答）。
  - 如果某一題看不清楚、無法確定文字內容，請標注「無法辨識」，不要用猜的方式填補。
  - 不要在這一步替換文字、簡化題目或生成任何新的選項。
完成標準：
  - 我會拿這份抽取結果和原始 PDF 逐題比對，確認題目與答案文字一致才會進入下一步。
  - 若比對時發現落差，我會指出題號，請你只重新抽取該題，不要重新處理全部。

［附上 PDF 檔案］
```

**查核點**：每人手上有一份「原始題號、頁碼、題目原文、答案原文、題型」齊全的抽取表，尚未核對前不進入下一步。

---

## 七、步驟 3：抽取結果核對（15 分）

**核對方式**：題數不多時建議全數核對；題數較多、時間有限時，採「抽樣核對＋首尾必查」原則——至少核對開頭 3 題、結尾 3 題，加上中間隨機抽 5 題。若抽樣發現任一題有落差，改為全數核對，不可跳過此步驟直接進入轉換階段。

**核對重點**：

- 題目文字是否與 PDF 原文一致（尤其數字、單位、專有名詞）。
- 答案是否與 PDF 原文一致（不是 AI「順手」修正過的版本）。
- 標記「無法辨識」的題目，人工回頭確認 PDF 該處內容，補齊或決定放棄該題。

**若發現抽取錯誤**：只請 AI 重新抽取該題（沿用任務卡 1，限制欄加註「只重新處理第＿題」），不要整批重跑，避免已核對正確的題目被意外改動。

---

## 八、步驟 4：非選擇題轉選擇題（20 分）——任務卡 2

針對步驟 2 標記為「簡答填空計算」的題目，請 AI 保留原答案為正確選項，另外設計三個錯誤選項。已是選擇題的題目直接沿用原有選項，跳過此步驟。開放式問答題若決定不轉換，同樣跳過，於步驟 6 標記處理方式。

### 任務卡 2：非 MCQ 轉 MCQ 任務卡

```
目標：請把以下已核對過的題目，轉換成四選一的選擇題格式；正確答案維持原答案不變，
      請你另外設計 3 個錯誤選項。
情境：這些題目原本是（簡答／填空／計算）題，學生要在自主練習網頁上以點選的方式作答，
      需要固定為「一題一個正確答案＋三個錯誤選項」的格式。
限制：
  - 正確答案必須與我提供的原始答案完全一致，不可更動或「修正」原答案。
  - 三個錯誤選項須「似是而非」：常見錯誤理解、計算中容易犯的錯、看起來合理但確實錯誤，
    不要出現明顯荒謬、一看就知道錯的選項，也不要出現「以上皆是／以上皆非」。
  - 錯誤選項之間也不能彼此矛盾或自相矛盾。
  - 若某一題的性質不適合轉換成單一選擇題（例如需要多步驟申論、答案不唯一），
    請標注「不建議轉換」並說明原因，不要勉強生成。
完成標準：
  - 每題恰好 4 個選項，其中且僅有一個對應原始答案。
  - 我會逐題核對錯誤選項是否合理、是否可能也「說得通」而造成爭議。

［附上已核對過的原始題目與答案表］
```

---

## 九、步驟 5：選擇題品質與答案一致性核對（20 分）——任務卡 3

逐題對照第十節「干擾選項設計品質檢核清單」與原始 PDF 答案，發現問題就用下面的任務卡請 AI 只修正該題。

### 任務卡 3：選擇題修正任務卡

```
目標：請協助我檢查並修正以下第＿題轉換後的選擇題。
情境：我核對後發現（錯誤選項其實也可能對／錯誤選項太離譜／正確答案跟原始 PDF 答案
      不一致／題幹轉成選擇題後語意不清楚）。
限制：正確答案必須維持與原始 PDF 一致，不可更動；只調整有問題的選項或題幹措辭。
完成標準：修改後 4 個選項唯一對應一個正確答案，錯誤選項合理但不含糊，且與原始 PDF 答案一致。
```

## 十、干擾選項（錯誤選項）設計品質檢核清單

這份清單是本模組相對於通用版 M2／M3 新增的內容，因為 PDF 轉換情境下「生成錯誤選項」是全新的工作，通用版的題組品質清單（`模組設計規劃.md` 附錄 C-1）沒有涵蓋這一塊：

- [ ] 每個錯誤選項看起來都「有可能是對的」，不是一眼看穿的胡扯。
- [ ] 錯誤選項反映常見誤解、計算疏失或概念混淆，而不是隨機湊數。
- [ ] 沒有「以上皆是」「以上皆非」「以上都對」這類選項（無法有效鑑別學生是否真的理解）。
- [ ] 選項長度與敘述風格大致一致，避免正確答案因為「特別長」或「特別完整」而被學生猜中。
- [ ] 錯誤選項彼此之間不互相矛盾，也不會同時都可被解讀為正確。
- [ ] 選項不依賴原始 PDF 才看得懂的縮寫或上下文，題目本身要能獨立理解。

## 十一、與原始 PDF 的一致性——核心風險控管

這是本模組與通用版 M2／M3 最大的不同：通用版「創作新題目」對 AI 自由度較高，只要教師把關題目品質即可；本模組的正確答案來自**既有、權威的來源文件**，最大風險是 AI 在抽取或轉換過程中**悄悄偏離原始答案**，而不是題目「好不好」。因此本模組刻意設計兩個獨立核對關卡，缺一不可：

- **第一關（步驟 3）**：核對「抽取是否忠實」——防止 AI 看錯或看漏 PDF 內容。
- **第二關（步驟 5）**：核對「轉換是否忠實」——防止 AI 在生成錯誤選項時，答案本身也被不自覺改動或替換。

兩關對應的錯誤型態不同，任何一關被省略，錯誤都有可能無聲無息進入最終題組。

**若 AI 對原始答案提出質疑**（例如認為 PDF 上的答案本身有誤）：一律先假設是抽取或辨識問題，由教師人工回頭核對原始 PDF 確認；若確認 PDF 原答案確實有誤，由教師決定是否更正，並在題組中記錄「已依教師確認更正」，**不可由 AI 逕自變更答案**。

**建議**：定稿檔案（步驟 6）保留「原始題號／頁碼」欄位，方便日後回頭追溯到原始 PDF；此為 `模組開發計畫.md` D04 資料格式的選填擴充欄位。

---

## 十二、步驟 6：彙整定稿為統一資料格式（10 分）

沿用 `模組開發計畫.md` D04 的資料 schema，本模組建議加一個選填欄位 `source_ref`（原始題號／頁碼）：

```json
[
  {
    "id": 1,
    "question": "題幹文字",
    "options": {
      "A": "選項A文字",
      "B": "選項B文字",
      "C": "選項C文字",
      "D": "選項D文字"
    },
    "answer": "B",
    "explanation": "（可選）簡短解析",
    "source_ref": "原PDF 第12頁 第7題（選填，供日後追溯）"
  }
]
```

定稿前確認：欄位無缺漏、`answer` 對應到實際存在的選項代碼、不轉換的題目已從最終題組中移除或另存清單（不可遺留在題組中造成資料不完整）。

## 十三、常見情境與因應

| 情境                                      | 因應方式                                                                            |
| ----------------------------------------- | ----------------------------------------------------------------------------------- |
| 掃描版 PDF 文字辨識錯誤（尤其數字、符號） | 優先處理；若 AI 沒有圖像閱讀能力，人工重新謄打有問題的題目文字後再交給 AI           |
| 數學公式／化學式轉文字後失真              | 該題保留原始呈現方式或跳過轉換，標注「建議教師手動處理」                            |
| 題目引用圖表／圖片作為選項內容            | 純文字選擇題工具較難呈現，建議跳過或改寫為不依賴圖片的題幹                          |
| PDF 題數遠超過可處理範圍                  | 依步驟 0、1 的範圍限定原則，先處理子集，其餘留待會後套用同一套任務卡處理            |
| 抽取核對（步驟 3）發現 AI 大量看錯        | 停止進入轉換階段，先解決抽取正確率問題（換頁碼範圍、檢查 PDF 品質、必要時人工謄打） |
| 部分題目判定「不建議轉換」                | 明確標記處理方式（跳過／簡化為概念題／會後處理），不遺留在定稿題組中                |

## 十四、模組查核點與交付

保底標準（對齊 `模組設計規劃.md` 附錄 C-2 前半段，補上本模組專屬項目）：

- [ ] 已完成 PDF 前處理檢查，確認範圍與可行性。
- [ ] 已產出「原始題目／答案抽取表」，並完成核對（抽樣或全部）。
- [ ] 已將可轉換的題目轉為四選一選擇題，且正確答案與原始 PDF 一致。
- [ ] 每題錯誤選項已依第十節清單檢核。
- [ ] 定稿題組已存成統一資料格式（試算表或 JSON），可直接交給 M4 vibe coding 階段。
- [ ] 不適合轉換的題目已明確標記處理方式，而非遺留在題組中造成資料不完整。

## 十五、與既有文件的關係
