# AI Agent Prompt：統測試題下載與切題流程

把「下載指定學年度／群類的統測試題與標準答案」＋「切成單題圖片並產出答案 JSON」整理成可重複使用的提示詞。換學年度／群類時只需改「參數」區塊。

---

## 參數（每次使用前先填）

- 學年度：115
- 群類：電機與電子群資電類
- 需要的考科：專業科目(一)、專業科目(二)
- 下載檔案存放：`./module2/raw`
- 切題成果存放：`./module2/assets`

---

## 完整提示詞（可直接整段貼給 Agent）

```text
請完成以下兩階段任務。

【階段一：下載試題與標準答案】
1. 前往 https://www.tcte.edu.tw/ → 首頁「考生網路服務」找「{學年度}四技二專試題與答案公布」（通常在 https://web1.tcte.edu.tw/EXAM/{學年度}_4y/）。
2. 在科目對照表找「{群類}」列，取專業科目(一)(二)的「試題」與「標準答案」PDF。這些下載按鈕是 <input type="image" onclick="location.href='downloader.php?obj=<base64>'">，不是 <a href>，需讀該元素的 outerHTML/onclick 取出網址（obj 是檔名的 base64，可解碼核對科目，避免抓錯）。
3. 下載 4 個 PDF（帶 Referer header，否則可能被拒），存到 {下載檔案存放}，命名：專業一題目.pdf、專業一答案.pdf、專業二題目.pdf、專業二答案.pdf。
4. 打開每份 PDF 核對標題頁群類/科目名稱、頁數、答案題號範圍（通常 50 題）是否相符，不要只憑下載成功就判定完成。

【階段二：切題＋產出答案 JSON】
輸出：
  - {切題成果存放}/{學年度}專業1Q<題號>.png、專業2Q<題號>.png（各 50 張）
  - {切題成果存放}/{學年度}keys.json（key＝圖片檔名含 .png，value＝正確答案）

已知陷阱（務必依此處理，不要憑直覺重新設計）：
1. 用 PyMuPDF 以「行」為單位取座標，依頁碼→y→x 排序成閱讀順序清單再逐行掃描（PDF block 常含多題，只看 block 首行會漏題號）。
2. 判斷題號行：用「預期下一題」游標依序找 `^{N}\.\s`（句點後要求空白），避免封面「1.請核對…」這類無空白編號清單被誤判成題目。掃完檢查 1~50 是否齊全。
3. 題組「▲閱讀下文，回答第X-Y題」：第一題（X）裁切上邊界直接延伸到提示行即可；X+1 之後的題目要分別裁「共用說明區塊」＋「該題自己區塊」再垂直拼接（共用說明不會重複印出，不能只用單一矩形裁切）。
4. 下邊界＝下一題（或下個題組提示行）的起點，不加 padding（否則裁進下一題）；上邊界可留一點 padding 當視覺留白。
5. 支援跨頁裁切：起點頁裁到頁尾邊界（約 y=805pt，需實測），終點頁從頁首邊界（約 y=62pt）裁到終點，中間整頁納入，再垂直拼接。
6. 裁切用整頁寬度，不要只裁文字欄寬度（電路圖等常超出文字欄範圍）。
7. 用 `get_pixmap(matrix=fitz.Matrix(zoom, zoom))`，zoom ≥ 2.5，避免文字模糊。
8. 答案 PDF 表格用 `get_text()` 抽出後是逐格 token；用游標掃描，遇數字時看下一格是否為合法答案（A/B/C/D 或組合如 "AD"）才配對並前進兩格，否則只前進一格（表格末幾欄題號有印、答案格空白，簡單雙格配對會整批錯位）。只留 1~50。
9. 若有備註「答案變更為A或D皆可」，value 填多字母（如 "AD"），忠實反映公告。
10. JSON key 需與圖片檔名完全一致（含 .png）。

完成後抽樣檢查（純文字題／含圖表題／題組首題／題組非首題／跨頁題組／最後一題），確認無裁切錯位、重疊或截斷，且 JSON 題數與圖片張數一致（各科 50 題，共 100 張圖、100 筆 JSON）。
```

## 備註

- 此版本依「115 學年度統測 電機與電子群資電類」實跑一次、修正
  裁切重疊與答案配對兩個 bug 後整理而成。換學年度／群類時，版面
  座標（頁首約 62pt、頁尾約 805pt）建議先抽一頁量測確認，不同
  年度模板若調整過要跟著改。
- 與同資料夾 `AI_Agent_教學應用工作坊02_模組一_從教材產生題組.md`
  互補：那份講「PDF 題目/答案 → 選擇題題組」的教學設計流程（人在
  迴圈品質把關），本文件講「取得 PDF＋切成單題圖片」的技術執行
  細節，是題組製作更前置、更偏工程的步驟。
