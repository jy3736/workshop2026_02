## 工作坊簡介

上一場工作坊，我們練習把教學需求說清楚，並與 AI Agent 協作完成可檢查、可修正的小任務。這一場將把這個能力真正做成一個可用的教學工具：教師帶著自己正在教授的主題、教材、講義或簡報進場，與 AI Agent 協作產生一份多題式選擇題題組（例如 10、20 或 30 題），再以 vibe coding 的方式，把題組與功能需求交給 AI，製作一個可在個人電腦本機開啟的靜態 HTML 自主練習小工具。

選擇題作為起點，是因為規則清楚、容易批閱，對初次嘗試的教師與學生都較友善。AI 可協助教師整理與初步產生題組，但題目是否符合學習目標、答案是否正確、題幹是否清楚、選項是否合理，仍必須由教師檢核——這個過程正是在練習把教學專業轉為可以交給 AI 協助處理、但仍由人負責驗收的內容。

學生開啟網站時只看得到題目與選項，作答期間不會看到答案；完成作答並按下「送出並查看結果」後，網站才根據題組中的答案自動批閱，顯示答對題數、總分與逐題對錯，並可重新作答，反覆練習。學生也能把答錯的題目帶去與 AI 對話，追問為什麼答錯、正確概念是什麼、可能誤解了哪裡，形成「教材 → 題組 → 自主作答 → 自動回饋 → AI 釐清迷思 → 再次練習」的學習循環。

本場的目標不是做出一套正式考試系統，而是完成一個可實際試用的自主學習原型。教師將親手體驗：只要能把需求說清楚，AI Agent 就能協助把教學想法逐步做成工具，也能在日後持續依自己的教學需要延伸與修改。

## 適合參與者

- 已參與工作坊（一），或能以「目標、情境、限制、完成標準」簡要描述自己的教學需求者。
- 想把自己正在教授的主題、教材、講義或簡報，轉化為學生可自主練習的選擇題題組與網頁工具者。
- 想讓學生在課後依自己的節奏反覆練習、獲得即時回饋並釐清迷思概念者。
- 希望先完成一個小而完整、可在本機使用的教學原型，而非從複雜系統開始者。

## 學習成果

完成本場後，您將能夠：

1. 依自己的課程主題或教材，與 AI Agent 協作產生一份多題式選擇題題組，並檢核題目、答案與選項的品質。
2. 將自我測驗需求拆成題庫資料、畫面、互動規則與驗收條件，並以 vibe coding 的方式與 AI 協作建立、修改一個單頁 HTML 自主練習小工具。
3. 設計「送出前不顯示答案，送出後才提供分數、逐題對錯與回饋」的基本學習流程。
4. 說明學生如何以批閱結果為起點，利用 AI 對話釐清答錯原因與未學會的概念。
5. 以試用與驗收清單檢查網站是否符合原先的教學需求。

## 工作坊重點

- 從教材、講義或簡報，與 AI Agent 協作整理成可練習的選擇題題組，維持題庫與網頁的清楚分工。
- 建立題目與選項畫面，記錄學生作答。
- 以 vibe coding 方式完成送出、計分、逐題正誤與正確答案回饋。
- 加入重新作答功能，讓學生可反覆練習。
- 設計學生利用 AI 釐清答錯原因、補強觀念的使用情境。
- 以同儕試用找出操作不清楚或需修正的地方。

## 事前準備

- 請攜帶筆記型電腦，並確認可使用網頁瀏覽器。
