AI Agent 實作環境建置

本模組聚焦在 Windows 11 筆電上，把「跟 AI Agent 協作」所需的三個部分準備好：先安裝並設定 ChatGPT 桌面 app（Chat、ChatGPT Work、Codex 三種工作介面）；再把 VS Code 裝好對應的擴充套件；最後申請個人 GitHub 帳號並送出 GitHub Education 驗證。三個部分彼此獨立，可以照自己的步調完成，最後再一起驗收。

學習目標 (Learning Objectives)

完成本模組後，學員應能：

  • 安裝並登入 ChatGPT 桌面 app，依任務性質選擇 Chat、ChatGPT Work 或 Codex 三種工作介面。
  • 在 VS Code 安裝 Codex 與 GitHub Copilot 兩個 AI Agent 擴充套件，讓 AI 能直接在編輯器裡協助讀寫、審查程式碼。
  • 在 VS Code 安裝並使用 Python、JavaScript、Markdown、HTML 的語法標示，以及 MS Office 文件（docx/xlsx/pptx）的直接預覽，不用切換到其他應用程式就能檢視教材。
  • 申請個人 GitHub 帳號，並送出 GitHub Education（教師／Global Campus）驗證申請。
  • 依 checklist 自行驗證三個部分是否設定完成，並排除常見問題。

三個部分總覽 (Overview of the Three Parts)

本模組要完成的三件事彼此獨立，可以照自己的步調依序完成：

部分 涵蓋內容
第一部分：ChatGPT App 安裝 ChatGPT 桌面 app，登入後熟悉 Chat、ChatGPT Work、Codex 三種工作介面的差異與切換時機
第二部分：VS Code + 擴充套件 安裝 VS Code，加裝 Codex 與 GitHub Copilot 兩個 AI Agent 擴充套件，以及 Python／Markdown／HTML 語法標示與 MS Office 文件預覽套件
第三部分：GitHub 帳號 + GitHub Education 註冊個人 GitHub 帳號，送出 GitHub Education（教師）驗證申請，取得後續課程與工具的教育版權益

第一部分：安裝與設定 ChatGPT App (Chat / Work / Codex)

ChatGPT 桌面 app 是 Windows 上進入 Chat、ChatGPT Work 與 Codex 三種工作介面的共同入口。

工具 官方下載／說明 建議指令或操作
ChatGPT 桌面 app OpenAI：ChatGPT desktop app for Windows winget install --id 9PLM9XGG6VKS --source msstore，或從 Microsoft Store 安裝。安裝後開啟 app，使用 ChatGPT 帳號登入。

登入後，依任務性質選擇正確的工作介面：

  • 需要快速問答時選 Chat。
  • 要完成研究、文件或需要審查的多步驟成果時，先選 ChatGPT，再切換到 Work。
  • 要處理課程 project、程式碼、指令與 diff 時，從產品選單選 Codex。

⚠️ 在 Codex 送出第一個任務前，先選先要求核准（Ask for approval），不要一開始就打開完整存取權（Full access），這樣才能在每一步都看清楚 Agent 打算做什麼、產生了哪些變更，再決定要不要放行。

驗收：執行 guided「Hello, AI Agent」任務（請 Codex 在專案資料夾建立一個 hello.txt），確認 AI Agent 能接收指令、產生檔案並回報結果。

第二部分：VS Code 與擴充套件

VS Code 是之後操作 AI Agent 的主要工作視窗，搭配下列擴充套件，就能在同一個視窗裡完成程式協作與教材檢視。

Python 語法標示 Python（Microsoft 官方擴充套件） ms-python.python

可在 VS Code 左側 Extensions 視窗搜尋安裝，也可在終端機逐行執行：

code --install-extension ms-python.python
code --install-extension yzhang.markdown-all-in-one

驗收：開啟 Extensions 視窗確認上述套件都已安裝並啟用；再分別開啟一個 .py、.md、.html，以及一份 .docx 或 .xlsx 檔案，確認語法標示或預覽畫面正常顯示。

第三部分：申請 GitHub 帳號與 GitHub Education

GitHub 帳號是後續課程管理專案、儲存檔案的基礎；GitHub Education 則能讓教師身分取得 Copilot 等工具的教育版權益。

步驟 說明
註冊 GitHub 帳號 前往 github.com/signup 完成註冊；建議使用學校網域信箱，方便之後的教師身分驗證與通知
申請 GitHub Education（教師） 登入後前往 github.com/education/teachers，依指示提供任教證明（學校信箱驗證、教職證明文件或課程頁面連結）
等待審核 審核通常需要數個工作天；審核期間仍可正常使用 GitHub 帳號本身的功能，教育版權益要核准後才會生效

學校信箱不是必要條件，但用學校網域信箱註冊，通常能加快 GitHub Education 的自動驗證流程。

驗收：確認已登入 github.com；確認 GitHub Education 申請已送出（畫面顯示「Application submitted」，或已顯示核准後的權益頁面）。

AI Agent Hands-on Environment Setup

This module prepares three things you need to work with an AI agent on a Windows 11 laptop: install and configure the ChatGPT desktop app (Chat, ChatGPT Work, and Codex); install VS Code with the matching extensions; and register a personal GitHub account and submit a GitHub Education application. The three parts are independent — work through them at your own pace, then check off all three at the end.

Learning Objectives

After this module, participants can:

  • Install and sign in to the ChatGPT desktop app, and choose Chat, ChatGPT Work, or Codex for the task at hand.
  • Install the Codex and GitHub Copilot extensions in VS Code so the AI agent can read, write, and review code directly in the editor.
  • Install and use syntax highlighting for Python, JavaScript, Markdown, and HTML in VS Code, plus direct previews for MS Office files (docx/xlsx/pptx), without switching to another app to view course material.
  • Register a personal GitHub account and submit a GitHub Education (teacher / Global Campus) verification application.
  • Use the checklist to verify all three parts are set up and troubleshoot common issues.

Prerequisites

Item Description
Personal laptop Windows 11, with administrator (software installation) permissions
Network Internet access to download installers, register accounts, and reach AI services
ChatGPT account A ChatGPT account with Codex access; if you don't have one, create it on the website or the first time you launch the desktop app
Email address A school-domain email is recommended — used to register a GitHub account and apply for GitHub Education, and it speeds up faculty verification
Basic skills Comfortable opening a browser, and downloading and running an installer

Overview of the Three Parts

The three things this module covers are independent of each other — work through them in whatever order suits you:

Part Covers

Part 2: VS Code + Extensions Install VS Code, add the Codex and GitHub Copilot AI-agent extensions, plus Python/Markdown/HTML syntax highlighting and an MS Office document preview extension

Part 1: Install and Configure the ChatGPT App (Chat / Work / Codex)

The ChatGPT desktop app is the shared entry point on Windows for Chat, ChatGPT Work, and Codex.

Tool Official Download / Notes Recommended Command or Steps
ChatGPT desktop app OpenAI: ChatGPT desktop app for Windows Run winget install --id 9PLM9XGG6VKS --source msstore, or install it from the Microsoft Store. Then open the app and sign in with your ChatGPT account.

After signing in, pick the right interface for the task:

  • Use Chat for quick questions.
  • Select ChatGPT, then Work, for research, documents, or a multi-step, reviewable outcome.
  • Select Codex from the product menu for a course project, code, commands, and diffs.

⚠️ Before sending the first task in Codex, choose Ask for approval; don't enable Full access by default. That way you can review what the agent intends to do and what it changed at every step, before deciding whether to approve it.

Check: run the guided "Hello, AI Agent" task (ask Codex to create a hello.txt file in the project folder) to confirm the AI agent can receive instructions, produce a file, and report back.

Part 2: VS Code and Extensions

VS Code is the main window for working with the AI agent later. With the extensions below, you can handle both code collaboration and course-material review in the same window.

⚠️ Extension IDs change as the Marketplace is updated. Before the live session, search each name in the Extensions panel to confirm the ID is still correct — especially the Office document preview extension, which is the least mainstream of the set.

Check: open the Extensions panel and confirm the extensions above are installed and enabled; then open a sample .py, .md, .html, and a .docx or .xlsx file, and confirm syntax highlighting or the preview renders correctly.

Part 3: Apply for a GitHub Account and GitHub Education

A GitHub account is the foundation for managing projects and files in later modules; GitHub Education lets a verified teacher unlock education-tier benefits for tools like Copilot.

Step Description
Register a GitHub account Go to github.com/signup and complete registration; a school-domain email is recommended to speed up later faculty verification and notifications
Apply for GitHub Education (teacher) After signing in, go to github.com/education/teachers and follow the prompts to provide proof of teaching (school email verification, a faculty ID document, or a link to your course page)
Wait for review Review usually takes a few business days; you can keep using the GitHub account itself while you wait, but the education-tier benefits only apply once approved

A school-domain email isn't required, but registering with one usually speeds up GitHub Education's automatic verification.

Check: confirm you're signed in at github.com; confirm the GitHub Education application has been submitted (the page shows "Application submitted", or already shows the approved benefits page).
