大家好，歡迎收聽這系列的深度解析節目，我是主持人。這系列一共會帶你走過四個模組，把一套完整的「Vibe Coding 加 AI Agent」工作坊內容，用聲音的方式重新講一次給你聽。今天先從第一個模組開始，主題是：在 Windows 11 筆電上，把跟 AI Agent 協作需要的三個部分準備好。

先說說什麼是 Vibe Coding。簡單講，它指的是一種新的工作方式：你不再是自己一行一行敲程式碼，而是用自然語言，跟一個 AI Agent 對話，描述你想要什麼，讓它去寫程式、改檔案、下指令，你則負責檢查結果、決定要不要放行。這一集要準備的三件事，就是支撐這整套工作方式的最基本環境。

這個模組跟大家想像的「灌好整套開發工具鏈」不太一樣，這次刻意把範圍縮小到三個部分，而且彼此獨立，不用照順序做完才能開始下一個。第一部分，是安裝並設定 ChatGPT 桌面 app，也就是 Chat、ChatGPT Work，跟 Codex 這三種工作介面的共同入口。第二部分，是把 VS Code 裝好，再加上幾個擴充套件：一個是 Codex，讓你在編輯器裡直接跟 AI Agent 協作寫程式；一個是 GitHub Copilot，提供程式碼自動完成跟 Copilot Chat；剩下幾個，則是讓 VS Code 能直接檢視 Python、JavaScript、Markdown、HTML，還有 Word、Excel 這類 MS Office 文件的語法標示跟預覽套件，不用切換到別的應用程式就能看教材。第三部分，是申請個人的 GitHub 帳號，並且送出 GitHub Education 的教師身分驗證申請，通過之後就能拿到像 Copilot 這類工具的教育版權益。

先說第一部分。ChatGPT 桌面 app 在 Microsoft Store 就能找到，用 winget 指令也能裝，裝好之後打開來，用你的 ChatGPT 帳號登入。登入之後，要學會依任務性質切換三種工作介面：需要快速問答，就用 Chat；要做研究、寫文件，或者做那種需要審查過程的多步驟任務，就選 ChatGPT，再切到 Work；真的要動到課程的 project、程式碼、指令跟 diff，才切到 Codex。這裡有個安全習慣要特別提醒：在 Codex 裡，送出第一個任務之前，記得先選「先要求核准」，不要一開始就打開「完整存取權」，這樣你才能在每一步都看清楚它打算做什麼、產生了哪些變更，再決定要不要放行。這部分的驗收，是跑一次「Hello, AI Agent」的暖身任務，請 Codex 幫你在專案裡建立一個 hello.txt，確認整個「下指令、Agent 執行、你檢查結果」的迴圈跑得通。

第二部分是 VS Code 跟擴充套件。VS Code 本身可以用 winget 裝，裝好之後，把六個擴充套件補齊：openai.chatgpt 是 Codex 的編程代理，跟桌面 app 共用登入；GitHub.copilot 是 GitHub Copilot；ms-python.python 負責 Python 的語法標示；JavaScript 跟 TypeScript 其實 VS Code 內建就有支援，不用另外裝；Markdown 的部分用 yzhang.markdown-all-in-one，可以做語法標示跟即時預覽；HTML 用 ms-vscode.live-server，也就是 Live Preview，可以直接在編輯器裡看網頁畫面；MS Office 文件的部分，用 cweijan.vscode-office，這樣 Word、Excel 檔案不用另外開啟應用程式，在 VS Code 裡就能直接看。這裡要提醒一件事：擴充套件的 ID 會隨著 Marketplace 更新而改變，尤其是 Office 文件預覽這款比較小眾的套件，正式上課前最好先到 Extensions 視窗裡搜尋一次，確認名稱跟 ID 還是對得上。這部分的驗收，是打開 Extensions 視窗確認套件都裝好、啟用了，再分別打開一個 .py、一個 .md、一個 .html，還有一份 .docx 或 .xlsx 檔案，看語法標示跟預覽畫面是不是都正常顯示。

第三部分是申請 GitHub 帳號跟 GitHub Education。GitHub 帳號本身很單純，去官方註冊頁面填一填就好，這裡的小建議是盡量用學校網域的信箱註冊，因為後面申請 GitHub Education 的教師身分驗證，會需要驗證你是不是真的在學校任教，用學校信箱通常可以加快這個自動驗證的流程。註冊完帳號之後，登入去 GitHub Education 給教師的申請頁面，照畫面指示提供任教證明，可能是學校信箱驗證，也可能是教職證明文件，或者一個課程頁面的連結。送出之後通常要等幾個工作天才會審核完成，等待期間帳號本身還是可以正常使用，只是教育版的權益要核准之後才會生效。這部分的驗收很單純：確認自己登入得了 GitHub，然後看一下 Education 申請的狀態，是已經送出，還是已經核准顯示出權益頁面。

聽到這裡，你可能會發現，跟上一個版本比起來，這個模組把 Git、Node.js、npm、uv，還有 GitHub CLI 這些工具都拿掉了。這不是漏掉，是刻意的設計：後面第二、第三、第四個模組，其實只要求「Codex 能正常開啟並使用」這一個前提，並不需要你在終端機裡操作版本控制或套件管理員。與其把時間花在裝一整套可能用不到的工具鏈，不如把這一集聚焦在真正會用到的三件事上。

最後，把三個部分都設定完成之後，可以照著模組裡的 checklist 做一次總驗收：ChatGPT App 檢查，三種工作介面都能正常開啟登入，Codex 能跑完 Hello, AI Agent 任務；VS Code 擴充套件檢查，語法標示跟文件預覽都正常顯示；GitHub 帳號檢查，帳號能登入，Education 申請已經送出或核准。三項都過了，這個模組就算完成。

好，那第一集就先到這裡。下一集，我們會走進第二個模組，看看怎麼把一份技專校院入學測驗中心的考古題 PDF，變成一題一張乾淨的圖片，再配上一份標準答案的資料檔。謝謝收聽，我們下一集見。
