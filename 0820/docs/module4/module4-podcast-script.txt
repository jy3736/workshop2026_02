大家好，歡迎回到深度解析節目，這是系列的第四集，也是最後一集。前面三集，我們搭好了環境，把考古題 PDF 變成問題集資料夾，第三集又練習了怎麼不套用任何現成工具，自己一句一句跟 Codex 描述想要的學生自我測驗網頁。這一集要做的事情，其實很簡單：把「自己描述需求」這件事，換成直接套用工作坊講師已經寫好的現成工具，一句話把整件事做完。

先講清楚這一集的定位。如果你已經跟著前面走完第三個模組，練習過從最精簡到最完整的三種說法，那這一集，就是給你的捷徑版：不用自己想該怎麼描述，只用一句話，請 Codex 套用工作坊講師事先寫好的 build-quiz-app 這個現成工具，直接生成一個不用架站、雙擊就能打開的學生自我測驗網頁。而且這裡有個第三集現在沒有的東西：這個現成工具還會順便附上一個教師端成績彙整頁，讓老師可以把全班的成績檔案收集起來看。如果你還沒走完第三個模組，或者當時想跳過「自己描述需求」這個練習，這一集也完全可以直接照做，只是背後實際發生了什麼，全部交給 Codex 處理，你不需要知道任何技術細節。

這裡有一個小細節值得先提醒。第二個模組用的那些現成工具，放在專案裡的 .claude/skills 資料夾底下；但這一集用的 build-quiz-app，是放在 .agents/skills 這個資料夾底下。為什麼要特別講這個路徑？因為 Codex 不像某些工具那樣，會自動偵測專案裡有哪些工具可以用，所以下指令的時候，得直接把工具放的位置講清楚，讓 Codex 能直接找到並使用。如果你的專案裡還沒有這個 .agents 資料夾，模組裡有提供一個壓縮檔可以下載，解壓後把資料夾放到專案根目錄，跟其他模組資料夾同一層就可以了。

再來是這一集另一個值得特別說明的改動：這個模組現在跟第三個模組共用同一份問題集資料夾，都放在 module3 底下，不再各自準備一份。裡面目前有兩組範例：一組是數學(A)，共同科目二十五題，已經套用過這個工具，做出了一個可以直接雙擊打開的成品；另一組，是電機與電子群資電類的專業科目一跟二，總共一百題，資料已經準備好，但還沒加進測驗清單裡，正好可以用來示範這一集的重點。

那一句話怎麼下呢？其實就是直接跟 Codex 說：請對這組還沒加進去的問題集資料夾，套用本專案內的 build-quiz-app 這個工具，加入既有的測驗程式，不要覆蓋掉已經做好的數學(A)測驗。Codex 讀完工具的說明之後，會自己決定輸出的成果要放在哪裡、自己跑資料夾分析、自己寫設定、自己打包，你完全不需要插手中間任何一步。因為既有的測驗程式裡已經有數學(A)這一份了，Codex 應該會先問你要不要加進去，確認之後，看到它回報完成，就可以進入驗收了。

驗收的重點很單純，三件事。第一，輸出的地方應該出現一個新的測驗網頁檔案，檔案大小大約是問題集圖片總大小的一點三七倍，這是圖片編碼成文字塞進網頁造成的膨脹，如果明顯小很多，通常代表圖片沒被完整塞進去。第二，直接雙擊打開那個檔案，不要另外開伺服器，輸入姓名、選一個較小的題數、作答幾題、按送出，確認會出現分數跟逐題對錯的畫面。第三，如果 Codex 回報有題目因為缺圖被跳過，先自己確認能不能接受這個結果，不要視而不見，答案檔裡的題目數跟畫面上能抽到的題數，應該要吻合。

測驗網頁做好之後，還有教師端這一塊，這正是這個模組跟第三集不一樣的地方。學生在測驗頁面送出作答後，畫面上會有一顆下載成績單的按鈕，把這次作答的逐題結果存成一個能用 Excel 打開的檔案。教師端有一個成績彙整頁，一樣雙擊即可開啟，不需要架站，也不會把資料上傳到網路上。老師把收到的成績檔案拖曳到頁面上的拖放區，就會自動彙整出每位學生的成績，還有每一題全班的答對率。

這一集也安排了一個動手做的練習，是加入第三份測驗。跟前面不一樣的地方是，目前資料夾裡沒有預先準備好、還沒處理的原始試題，得自己動手準備。第一步，照第二個模組教的方式，挑一份你自己感興趣的考古題 PDF，或者手邊已經有的任何一份，走一次「下載、切題、清理」的完整流程，得到一組新的「題目圖片加正確答案」資料夾，存到跟現有兩組同一層的位置。第二步，資料準備好之後，跟 Codex 說一聲：這個問題集資料夾也做好了，請比照剛剛的方式，套用同一個工具，把它加進既有的測驗程式裡，不要動到原本已經做好的那幾份。Codex 會自己判斷既有的測驗程式已經存在，用「加一筆新設定」的方式處理，而不是整個重建。完成之後，測驗清單裡應該多一筆設定，輸出的地方也應該多一個檔案，原本已經做好的那幾份完全不受影響。這正好證明了一件事：加入新測驗，不需要重新設計工具。

聽到這裡，可能有人會問：那我是不是就再也不用碰第三集講的那些內容了？我覺得答案是，大多數時候，這裡的一句話真的就夠了；但有幾種狀況，回頭看第三個模組會有幫助。比如說，你還沒練習過怎麼自己跟 Codex 描述需求，想從最精簡的說法練到最完整的說法，累積下次遇到沒有現成工具可用的專案時，也能自己開口的能力；或者這裡套用現成工具做出來的結果不符合預期，想知道除了「套用一次」之外，還有沒有別的講法可以達到同樣的效果；又或者手上的問題集資料夾格式比較特殊，想先看看第三集怎麼一步步跟 Codex 討論這類狀況。不管走哪一條路，遇到問題時的處理方式其實都一樣：把你實際看到的狀況描述給 Codex，請它幫你檢查、修好，不用自己猜是哪裡出了問題。

最後有一個提醒，我覺得很重要，值得放在整個系列的結尾：如果你的問題集內容，是有版權疑慮的考古題，比如技專校院入學測驗中心的試題，在把雙擊即用的網頁正式交給學生之前，一定要再次確認自己有沒有合法散布這些內容的權利。這不是技術問題，是使用這整套工具時，你身為老師該負起的責任。

好，那這四集的深度解析，就在這裡告一段落。從第一集安裝設定 ChatGPT App 跟 VS Code、申請 GitHub 帳號，第二集處理考古題資料，第三集練習自己跟 Codex 描述需求，到今天第四集套用現成工具一句話完成整套流程，這其實是一條很完整的路徑：先練習怎麼把需求講清楚，再享受現成工具帶來的效率。謝謝你一路聽到這裡，希望這系列的內容，能幫助你在自己的課堂上，也把 AI Agent 這套工作方式用起來。我們下次見。
