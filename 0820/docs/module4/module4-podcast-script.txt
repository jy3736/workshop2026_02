大家好，這一集是 Module 4「一句話產生自主測驗網頁快速教學」。

如果你已經完成 Module 2，手上有一組由每題一張 PNG 圖片和 keys.json 組成的問題集，這份教學會帶你走一條快速路徑。你不需要學寫程式，不需要另外安裝套件，也不需要開終端機；只要在 Codex 對話視窗輸入一句清楚的指令，就能把問題集轉成可直接雙擊開啟的學生自主測驗網頁。

先說明它和 Module 3 的關係。Module 3 是練習版：你不套用現成工具，自己一步一步描述需求，請 Codex 協助製作測驗網頁。Module 4 則是快速版：直接請 Codex 套用工作坊講師事先寫好的 build-quiz-app skill。這不是 Codex 原生內建的功能，skill 位於專案根目錄的 .agents/skills/build-quiz-app/。如果專案裡還沒有 .agents 資料夾，先下載 module4-agents-skills.tar，解壓後把 .agents 資料夾放在專案根目錄，和 module4 資料夾同一層。

本教學對應 module4 資料夾。這裡只有 app 這個輸出成品；問題集資料和 Module 3 共用，都在 module3/repo 底下，不用再複製一份。目前有兩組範例。第一組是 module3/repo/math-115a，內容是 115 學年度數學 A 共同科目二十五題，已經有可直接打開的成品，位置在 module4/app/dist/Formative_Assessment_115_MathA_quiz.html。第二組是 module3/repo/115，內容是 115 學年度電機與電子群資電類專業科目一和二，共一百題，尚未加入測驗清單；這一組正適合拿來練習。

請在 Codex 輸入下面這一句話：請對 module3/repo/115 套用本專案內 .agents/skills/build-quiz-app/ 的 skill，將它加入既有 module4/app/，不要覆蓋現有的數學 A 測驗。

Codex 會依照 skill 的說明分析問題集，在既有的 module4/app/config.json 新增一筆設定，並在 module4/app/dist 產生新的測驗。由於數學 A 測驗已經存在，skill 會先要求確認；請選擇加入既有 app，不覆蓋。你不需要自己找路徑、分析資料夾、寫設定或打包。

完成後，請做三項驗收。第一，在 module4/app/dist 底下，應出現新的 examLabel_quiz.html 檔案。它的大小大約會是問題集圖片總大小的一點三七倍，因為圖片會經過 base64 編碼嵌入網頁；如果明顯小很多，要留意圖片可能沒有完整嵌入。第二，直接雙擊開啟新的測驗檔案，不必另外開伺服器。輸入姓名，選較小的題數，作答幾題後送出，確認畫面會顯示分數和逐題對錯。第三，如果 Codex 回報有題目因缺圖而跳過，先確認你能否接受；keys.json 裡的題目數，應和測驗畫面可抽到的題數相符。

這個 module 還多了教師端成績彙整功能。學生送出作答後，可以按「下載成績單 CSV」，把本次逐題作答結果存成 CSV 檔。老師可直接雙擊開啟 module4/app/report-aggregator.html；它不需要架站，也不會把資料上傳到網路。只要把收到的多份 CSV 成績單拖到頁面的拖放區，就能得到每位學生的成績，以及每一題全班的答對率。學生端的 dist/*.html 是要交給學生的成品；report-aggregator.html 則是單獨交給老師使用的彙整工具，兩者用途不同。

接下來，你也可以加入第三份測驗。目前資料夾裡沒有第三份尚未處理的原始試題，所以先依 Module 2 的流程準備一組完整問題集：每題一張 PNG 圖片，以及一份題號與正確答案相符的 keys.json。再把它放到 module3/repo/新資料夾名稱/，和現有資料共用同一個問題集位置。

資料準備好後，請對 Codex 說：module3/repo/新資料夾名稱 已經是一組完整問題集，包含每題圖片與 keys.json。請套用 .agents/skills/build-quiz-app/，將它新增到既有 module4/app/ 的測驗清單，不要覆蓋已完成的測驗。

完成後，module4/app/config.json 應新增一筆 assessments 設定，module4/app/dist 也應多出一個新的測驗檔案；原有的數學 A 測驗和先前加入的測驗都要維持不變。再用剛剛的方式，雙擊開啟、作答、送出，完成驗收。

大多數情況，一句話就夠了。但如果你還想練習怎麼自己描述需求、現成 skill 的結果不符合預期，或問題集的檔名格式特別不規律，請回頭參考 Module 3 的詳細教學。無論選哪一條路，遇到問題時都把實際看到的情況描述給 Codex，請它檢查並修正，不必自己猜測問題原因。

最後提醒：之後每增加一組問題集，只要重複「Module 2 切題清理，然後一句話疊加進 app」的流程，app 引擎本身不需要重建。若問題集使用的是有版權疑慮的考古題，例如技專校院入學測驗中心的試題，在把可直接雙擊的 HTML 正式交給學生前，請再次確認自己是否有合法散布內容的權利。
