大家好，歡迎回到深度解析節目，這是系列的第二集。上一集我們把 Windows 11 上的 Vibe Coding 環境搭好了，這一集要正式進入內容面，主題是：怎麼把一份考古題的 PDF，變成一題一張乾淨的圖片，再配上一份標準答案的資料檔。這整套流程，最後會變成後面模組要用的「問題集資料夾」，所以你可以把這一集，想成是整個工作坊的原料準備站。

這個模組鎖定的資料來源，是技專校院入學測驗中心，也就是我們常說的統測，的考古題。整個流程分成三個階段，前一個階段的輸出，就是下一個階段的輸入，環環相扣：第一階段是下載，抓試題跟標準答案的 PDF；第二階段是切題，把整份 PDF 切成一題一張的圖片，同時對出一份「答案 JSON」；第三階段是清理，把圖片裡多餘的空白裁掉、把題號塗白。這三個階段各自對應一個工具，都是工作坊講師事先寫好的 custom skill，放在專案的 .claude/skills 資料夾底下，不是 Codex 原生內建的功能。跟 Codex 對話的時候，只要把你要做的事情講清楚，再提一句可以參考對應的工具，Codex 就會自己去讀說明、決定怎麼用。

模組裡準備了兩組範例資料，剛好示範兩種不同的起點。第一組是一百一十五學年度電機與電子群資電類的專業科目一跟二，總共一百題，這一組是「從零開始」，三個階段完整跑過一次。第二組是一百一十五學年度數學 B，共同科目，二十五題，這一組的 PDF 已經在手上，直接從第二階段的切題開始。為什麼會這樣？因為下載這個工具，目前只認得成績單頁面上「專業科目一」「專業科目二」這兩個列標籤，抓不到數學這種共同科目。這是這個工具目前的能力邊界，也是模組特別提醒的一點：如果你要練習的是共同科目，得自己先手動去網站下載 PDF，再從切題開始。

先講第一階段，下載。你只要用一句自然語言，跟 Codex 說清楚要抓哪個學年度、哪個群類，只要專業科目一跟二的試題跟標準答案，存到哪個資料夾，檔名保留系統原本的命名方式。跑完之後，資料夾底下應該會出現四個檔案：專業一的試題跟答案，還有專業二的試題跟答案。驗收的時候，有幾個重點：四個檔案都要出現，檔名要跟科目、群類對得起來；試題 PDF 大概十二頁，這是五十題專業科目考卷的正常頁數，標準答案 PDF 大概一頁，頁數差太多就要留意；最重要的是，請 Codex 打開下載到的 PDF，你自己用肉眼確認群類、科目對不對，不要急著往下一步衝。另外如果答案 PDF 裡出現「答案變更為」這類更正說明，切題階段的答案解析，會自動把像是 AD 這種多重答案收進去，但還是值得事後對照原文，確認真的有收進表格裡。

第二階段是切題。這一步把整份 PDF 切成一題一張的 PNG 圖片，並且對照標準答案 PDF，做出一份「圖片檔名對應正確答案」的 JSON 檔。同樣是一句話請 Codex 做：把試題 PDF 每一題切成一張圖片，檔名照規則命名，再對照標準答案做出 keys 這個 JSON 檔，key 要跟圖片檔名完全一樣，包含副檔名，value 放正確答案字母。這裡有個小地方要特別注意：如果切的是共同科目，像數學，題數通常是二十五題，不是五十題，一定要跟 Codex 說清楚正確題數；而且切題工具的輸出檔名裡，固定寫死「專業」兩個字，就算科目代號換成字母，也不會自動變成「數學」，所以切完數學卷之後，還是要另外請 Codex 把檔名改成數學開頭，keys JSON 裡的 key 也要同步修改。驗收的時候，要看圖片張數符不符合預期題數，keys JSON 的筆數要一樣多；如果考卷裡有題組，像是「閱讀下文，回答第幾題到第幾題」這種，要挑題組的第一題跟後面某一題，確認共用的閱讀文章有出現、沒有被截斷或重複貼兩次；再挑一題有電路圖或圖表的題目，確認圖片右邊沒有被切掉；看最後一題，確認內容完整，如果原本印有「以下空白」的提示，這裡應該還留著，要等到清理階段才會被裁掉；最後隨機抽兩三題的答案，跟標準答案 PDF 肉眼核對一次。

第三階段是清理，這一步做兩件事。第一件事，叫做 Pass 1，裁掉每張圖下面多餘的空白，包括「以下空白」那段殘留的文字，但不動真正的內容。第二件事，叫做 Pass 2，把題號，像是五十點、十一點這種數字加句點，塗白，但是選項 A、B、C、D 完全不能動。這兩段清理邏輯，是直接寫給 Codex 讀取之後、即場執行的，所以這一步一定要透過跟 Codex 對話來完成。這裡模組特別強調一個安全習慣：執行 Pass 2 之前，一定要先「乾跑」一次，把每張圖偵測到的題號區塊印出來讓你檢查，確認每張圖都剛好抓到一個題號區塊之後，才正式塗白存檔。為什麼一定要先乾跑？因為 Pass 2 判斷「這是不是題號」，用的是像素座標的門檻值，這組門檻是針對這份考卷的版面量身調校的。萬一某一年、某一科的版面跟預期不同，門檻就可能抓錯，乾跑只是印出偵測結果，不會真的動任何像素，讓你能在真的塗白存檔之前先發現異常，避免一次做壞整批圖片。驗收的時候，乾跑結果裡，每個檔案都應該剛好偵測到一個題號區塊，零個代表版面跟預期不同，兩個以上代表誤判，兩種情況都要先停下來人工檢查，不要跳過；接著抽查一題個位數題號、一題兩位數題號，確認題號真的不見了，也沒有留下半個數字的殘影；再抽查一張有 A 到 D 選項的圖，確認選項字母完整保留；抽查一張原本有以下空白的圖，確認空白已經裁掉，內容緊貼底部，留一點呼吸空間；最後整個資料夾掃一次，找找看有沒有圖片底部還留著一整行、跟前後文完全不相關的文字，這種情況不是清理階段能安全處理的，代表切題階段的邊界抓錯了，要回頭用切題工具重新切那一題，而不是在清理階段硬加規則修。

三個階段都跑完之後，模組安排了一個動手做的練習，讓你換一組資料，自己跑一次全流程。如果手邊已經有其他學年度或科目的 PDF，可以直接從切題跟清理兩個階段開始，跳過下載步驟；如果要完整體驗，就換一個你自己感興趣的學年度或群類，從下載開始，完整跑過三個階段，建議先請 Codex 用乾跑模式，確認群類名稱有比對到，再正式下載，避免白跑一次網路請求。

這一集的重點，其實可以濃縮成一句話：每個階段都要有明確的驗收動作，不要等三個階段都跑完才一次檢查，尤其清理階段的乾跑習慣，是避免一次做壞整批圖片的關鍵防線。清理乾淨的圖片，加上這份 keys JSON，就是後面模組要用的原始素材。下一集，我們會往下走，看看怎麼把這個問題集資料夾，變成一個學生可以自己打開作答的測驗網頁。謝謝收聽，我們下一集見。
