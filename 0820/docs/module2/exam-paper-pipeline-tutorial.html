考古題下載、切題與清理實作教學

這份教學帶你跟著做一次「PDF 考古題 → 一題一張乾淨圖片 ＋ 標準答案 JSON」的完整流程。你不需要自己寫程式，每個步驟都只要在 Codex 對話視窗裡用自然語言下指令即可完成。

本教學對應 module2/ 資料夾，裡面已經有兩組完整跑過的範例資料，你可以隨時打開來對照「正確結果長什麼樣子」。如果想跳過下載階段直接練切題，也可以下載 module2-raw.tar，解壓後會得到 raw/115/、raw/math-115b/ 這兩組原始 PDF。

學習目標

做完這份教學，你應該能夠：

  • 用 Codex，把技專校院入學測驗中心（統測）的考古題 PDF，轉成一題一張的乾淨圖片，加上一份標準答案 JSON。
  • 知道下載、切題、清理這三個階段各自在做什麼、為什麼要驗收、以及每個階段各自的能力邊界在哪裡。
  • 看得懂「乾跑（dry-run）先確認、沒問題才正式執行」這個安全習慣，並知道為什麼清理階段一定要先乾跑。
  • 自己換一個學年度／科目，獨立重跑一次完整流程。

先備條件

  • 已經能開啟並使用 Codex。若還沒設定好工作環境，請先參考 Module 1：Windows 11 環境建置。
  • 下載階段（步驟一）需要網路連線，因為要連到技專校院入學測驗中心的網站。
這三個工具都是工作坊講師事先寫好的 custom skill（一份說明文件 SKILL.md，加上對應的腳本），放在這個專案的 .claude/skills/ 資料夾底下（不是 Codex 原生內建的功能）。跟 Codex 對話時，把你要做的事講清楚，並提一句「可以參考 .claude/skills/ 底下對應的工具」，讓 Codex 自己去讀說明、決定怎麼用；如果它沒有主動找到，也可以直接請它打開指定的 SKILL.md 看說明。

整體流程總覽

整個流程分三個階段，前一階段的輸出就是下一階段的輸入：

階段在做什麼輸入輸出對應 skill
① 下載抓試題＋標準答案 PDF學年度、群類raw/<year>/*.pdfdownload-exam-pdf
② 切題把 PDF 切成一題一張圖，配對答案①的 PDFrepo/<name>/*.png ＋ keys.jsonslice-exam-pdf
③ 清理裁掉多餘空白、塗掉題號②的 png原地覆寫、變乾淨的 pngclean-exam-question-images

兩組範例資料剛好示範了兩種起點：115 學年度電機與電子群資電類是「從零開始」，三個階段都跑過一次；115 數學(B) 則是「PDF 已經在手上」，直接從步驟二開始 這是因為 download-exam-pdf 這個工具目前只認得「專業科目(一)(二)」，抓不到數學這種共同科目，這一點在步驟一會再說明。

步驟一：下載試題與標準答案 PDF

這一步的產出，是接下來切題階段要用的原始 PDF。如果你手上已經有 PDF 了（例如老師自己保存的考古題），可以直接跳到步驟二。

目前的能力邊界：download-exam-pdf 這個工具目前只認得成績單頁面上「專業科目(一)」「專業科目(二)」這兩個列標籤，抓不到「數學(A)/(B)/(C)」這類共同科目 這正是範例資料裡數學(B)直接跳過這一步、從切題開始的原因。如果你要練習的是共同科目，請自行到網站上手動下載 PDF，再從步驟二開始。

用一句話請 Codex 做

請到技專校院入學測驗中心的網站，幫我下載 115 學年度統測「電機與電子群資電類」的資料。
我只需要專業科目(一)、專業科目(二)的試題，還有這兩科的標準答案。
下載好之後存到 module2/raw/115，檔名保留系統原本的命名方式。

產出：module2/raw/115/ 底下會出現 4 個檔案：115專業一試題.pdf、115專業一答案.pdf、115專業二試題.pdf、115專業二答案.pdf。

驗收重點

  • 4 個檔案都出現，檔名跟科目、群類對得起來。
  • 試題 PDF 大約 12 頁（50 題的專業科目考卷），標準答案 PDF 大約 1 頁 頁數差太多要留意。
  • 請 Codex 打開下載到的 PDF，用肉眼確認群類、科目對不對，不要急著往下一步。
  • 如果答案 PDF 裡有「答案變更為…」這類更正說明，先留意一下，切題階段的答案解析會自動把多重答案（如 "AD"）收進去，但值得事後對照原文確認有沒有真的收進表格。

步驟二：切成單題圖片＋答案 JSON

這一步把整份 PDF 切成一題一張的 PNG 圖片，並且對照標準答案 PDF，做出一份「圖片檔名 → 正確答案」的 JSON。

用一句話請 Codex 做

請幫我把 module2/raw/115 底下 115 學年度試題 PDF，每一題切成一張圖片，
檔名用 module2/repo/115/115專業<1或2>Q<題號>.png。
再對照標準答案 PDF，做出 module2/repo/115/115keys.json，
key 要跟圖片檔名完全一樣（含 .png），value 放正確答案字母。

產出：module2/repo/115/115專業1Q1.png ～ 115專業1Q50.png、115專業2Q1.png ～ 115專業2Q50.png，加上一份 115keys.json，內容像這樣：

{
 "115專業1Q1.png": "B",
 "115專業1Q10.png": "B",
 "115專業1Q11.png": "A",
 ...
}

共同科目（例如數學）：題數不是 50 題，且檔名要手動改

共同科目考卷通常是 25 題，不是 50 題，記得跟 Codex 說清楚正確題數；另外 slice-exam-pdf 的輸出檔名固定寫死「專業」兩個字，即使科目代號換成字母也一樣，所以切完數學卷之後，檔名還是會叫 115專業BQ<n>.png，要請 Codex 另外改名成 115數學BQ<n>.png，keys.json 裡的 key 也要同步改。

用一句話請 Codex 做

請幫我把 module2/raw/math-115b 底下的 115 學年度數學(B) 試題 PDF 切成一題一張圖片，
這科是共同科目，只有 25 題，科目代號用 B。
輸出檔名請直接用 115數學BQ<題號>.png（不要用預設帶的「專業」字樣），
再對照標準答案 PDF 做出 keys.json，key 要跟檔名一致（含 .png），存到 module2/repo/math-115b。

驗收重點

  • 圖片張數符合預期題數（專業科目通常 50 題、共同科目通常 25 題），keys.json 的筆數要一樣多。
  • 如果考卷有「▲閱讀下文，回答第 X-Y 題」這種題組，挑題組的第一題和後面某一題各看一次，確認共用的閱讀文章有出現、沒有被截斷或重複貼兩次。
  • 挑一題有電路圖／圖表的題目，確認圖片右邊沒有被切掉。
  • 看最後一題，確認內容完整沒被切斷，如果原本有「【以下空白】」的提示，這裡應該還留著（要等清理階段才會被裁掉）。
  • 隨機抽 2、3 題的答案，跟標準答案 PDF 肉眼核對一次。

步驟三：清理圖片

切出來的圖片下緣常常會多留一小段空白，甚至帶到下一題的一小段殘影；題號（像「50.」「11.」）也還印在題目最前面。這一步做兩件事：

  • Pass 1：裁掉每張圖下面多餘的空白（包含「【以下空白】」的殘留），但不動真正的內容。
  • Pass 2：把題號（如「50.」「11.」）塗白，但選項 (A)(B)(C)(D) 完全不能動。

這兩段清理邏輯是直接寫給 Codex 讀取後即場執行的，所以這一步一定要透過 Codex 對話來做。

用一句話請 Codex 做

對 module2/repo/115 資料夾裡的每張 *.png：
1. 裁掉下面多餘的空白（含「以下空白」殘影），但不要裁到真正的內容。
2. 清掉題號（像「50.」「11.」），但 (A)(B)(C)(D) 選項不要動。
執行 Pass 2 之前，先「乾跑」一次，把每張圖偵測到的題號區塊印出來讓我看過，
確認每張圖都剛好抓到 1 個題號區塊之後，才正式塗白存檔。
為什麼一定要先乾跑：Pass 2 判斷「這是不是題號」用的是像素座標的門檻值（例如題號要在 x≤220 開始），這組門檻是針對這個考卷範本量身調校的。萬一某一年、某一科的版面跟預期不同，門檻可能會抓錯 乾跑只印出偵測結果、不會真的動任何像素，讓你能在「真的塗白存檔」之前先發現異常，避免一次做壞整批圖片。

驗收重點

  • 乾跑結果：每個檔案都剛好偵測到 1 個題號區塊。0 個代表版面跟預期不同，≥2 個代表誤判 兩種情況都要先停下來人工檢查，不要跳過。
  • 抽查一題個位數題號（如 Q1）、一題兩位數題號（如 Q50），確認題號真的不見了，而且沒有留下半個數字的殘影。
  • 抽查至少一張有 (A)～(D) 選項的圖，確認選項字母都完整保留。
  • 抽查一張原本有「【以下空白】」的圖，確認空白已裁掉、內容緊貼底部並留一點呼吸空間。
  • 整個資料夾掃一次：找找看有沒有圖片底部還留著一整行、跟前後文完全不相關的文字（不是幾個像素的小雜訊） 這種情況不是清理階段能安全處理的，代表切題階段的邊界抓錯了，要回頭用 slice-exam-pdf 重新切那一題，而不是在清理階段硬加規則修。

動手做：換一組資料，自己跑一次全流程

看懂範例之後，換你自己動手跑一次。建議照下面兩種難度挑一種：

基本版：從切題開始（不需要等網路下載）

如果你手邊已經有其他學年度或科目的 PDF（例如之前下載過、或同事給的），可以直接拿來練切題＋清理兩個階段，跳過下載步驟，輸出到一個新資料夾，不會動到 module2/ 裡已經驗證過的成果。比照步驟二，請 Codex 把試題切成一題一張圖片，輸出到 module2/repo/114-practice 這類新資料夾；切完之後，比照步驟三，請 Codex 對這個資料夾執行清理（記得先乾跑）。

完整版：從下載開始

換一個你自己感興趣的學年度或群類，從步驟一的下載開始，完整跑過三個階段。建議先請 Codex 用「乾跑」模式確認群類名稱有比對到，再正式下載，避免白跑一次網路請求。

練習時的自我檢查

  • 每個階段都做完該階段的「驗收重點」，不要等三個階段都跑完才一次檢查。
  • 如果卡在某個階段，回頭比對本教學開頭表格裡列出的範例資料（module2/repo/115、module2/repo/math-115b），看看「正確結果」長什麼樣子。
