大家好，歡迎回到深度解析節目，這是系列的第三集。前兩集我們把環境搭好了，也把考古題 PDF 變成了一題一張乾淨圖片、加上一份正確答案的問題集資料夾。這一集要處理的問題是：拿到這個問題集資料夾之後，要怎麼把它變成一個學生可以自己打開、自己作答、寫完馬上看到分數的測驗網頁？而且這一集有個前提，值得先說在前面：整集內容完全不會出現任何程式或技術名詞，從頭到尾就是你打字跟 Codex 講話而已。

先說明一下這一集的定位。工作坊講師其實已經事先準備好一個現成的小幫手，一句話就能請 Codex 用它，把整件事情快速做完，那是第四個模組要教的捷徑。但這一集，也就是第三個模組，刻意不用那個現成的小幫手，而是從只有一個問題集資料夾這個起點出發，你自己一句一句跟 Codex 描述你想要什麼、看它做出來的東西對不對，再決定要不要調整。目的不是要你學會寫程式，而是練習一件更根本的事：怎麼把需求講清楚，讓 AI Agent 聽得懂。等你做完這一集的流程，你會發現自己（跟 Codex）做出來的東西，其實跟第四模組一句話生成的成品是同一件事，只是這一集讓你多練習了一次怎麼開口。

整個設計，濃縮成一句話，就是你會對 Codex 說的：我手上有一份題目跟正確答案，麻煩幫我做成一個學生可以自己打開作答、寫完馬上看到分數的網頁。不用先弄懂任何技術名詞，就跟你平常請人幫忙做事一樣，把你想要什麼講清楚，剩下怎麼做，全部交給 Codex。整份教學其實只有三件事：把想要的成品講清楚、自己打開來試用一次、換一組新題目再試一次，順序做完就好，不需要拆成一堆技術步驟。

這一集的核心，是示範三種說法，從最精簡到最完整，讓你感受一下，同一件事可以講得多短、也可以講得多細，兩種都能請 Codex 做出堪用的成品。第一種，版本一，只講最核心的需求：我這裡有一個資料夾，裡面是題目圖片和正確答案；麻煩幫我做一個網頁，讓學生可以自己打開來做練習題，寫完可以看到分數；這個網頁要能直接雙擊打開就能用，不需要架設網站、也不需要連網路。這三句話，其他細節全部交給 Codex 自己判斷。第二種，版本二，在版本一的基礎上，多講清楚一點學生實際操作時會遇到的畫面：學生可以自己選擇這次要練習幾題，不用每次都寫完全部的題目；一題一題顯示題目圖片，讓學生選 A、B、C、D 這些選項作答；全部作答完、按下送出後，馬上顯示這次考了幾分、每一題答對還是答錯。第三種，版本三，把學生從打開網頁到看到結果的每一步都講清楚：先輸入姓名，再選擇這次要練習幾題；系統隨機抽題，一題一題顯示，如果某一題正確答案不只一個選項，也要能正確處理；作答完送出後顯示總分跟每一題對錯；還可以加一個按鈕，把這次作答的詳細結果存成一個能用 Excel 打開的檔案，方便留一份紀錄。這個版本做出來的成品，通常第一次就最貼近心裡想要的樣子。

這三個版本沒有標準答案，也沒有哪一種比較「正確」，重點是讓你知道：就算只用最短的版本開場，也不會做不出東西來，你隨時可以在 Codex 做完之後，再用一般的話請它補調整，不用一次就把所有細節講完美。

Codex 做完之後，接下來是打開來試用看看，這一步的心法是：不要只信任「Codex 說做完了」。先確認資料夾裡真的多了一個新的網頁檔案，直接對著它點兩下、雙擊打開，不用另外開瀏覽器輸入網址。接著自己當一次「假學生」：輸入一個姓名，選少一點的題數，比如五題，實際作答，按下送出，確認會出現分數，而且每一題的對錯看起來合理。如果請 Codex 加了下載結果的功能，也試著按按看，確認真的會存出一個檔案，並且能直接用 Excel 打開。如果哪一項卡住、畫面看起來怪怪的，或是出現看不懂的訊息，不用自己動手改任何東西，也不用猜是哪裡出了問題，直接把你實際看到的狀況，原原本本描述給 Codex 聽，請它幫你檢查、修好就好。

接下來是動手做的練習：換一組全新的題目資料，再做一次。這個練習的目的，是驗證請 Codex 做出來的東西，是不是真的能重複使用，而不是只對這一組資料剛好有效。做法很單純：準備一組新的題目資料夾，可以是你自己手邊已經有的考古題 PDF，也可以回到第二個模組，換一個你感興趣的學年度或科目重新做一次；接著跟 Codex 說一聲：我有一組新的題目資料夾，路徑是這裡，內容跟之前那兩組一樣，麻煩比照之前做的方式，幫我做出一樣的雙擊即用測驗網頁，加進同一個工具裡就好，不用整套重新做一次，也不要影響到已經做好的那幾份測驗。做完之後，照剛剛「打開來試用看看」的方式重新測一次，確認新題目能正常運作，而且原本已經做好的測驗完全不受影響，這正好證明「加新題目不用重新設計」這件事真的成立。

遇到問題的時候，這一集也整理了幾種常見狀況，邏輯都一樣：不用自己排查，只要把你觀察到的現象照著描述給 Codex 就好。比如題目數量看起來比資料夾裡實際的題數少，就跟 Codex 說你預期有幾題、實際抽到的比較少，請它確認是不是有題目的圖片對不起來；比如雙擊之後畫面空白或沒有反應，就把這個現象直接講給 Codex 聽；比如加了新題目之後，原本的測驗打不開了，也是同樣的做法，請 Codex 確認、修好。就算你完全不確定成品存在電腦的哪裡，也可以直接問 Codex：你剛剛做出來的網頁，實際存在哪一個資料夾、檔名叫什麼。

最後也提醒一下，這一份教學做出來的成品，正式交給學生之前，記得它應該是一個雙擊即用、不需要伺服器、不需要網路的單一個檔案；如果問題集內容是有版權疑慮的考古題，比如技專校院入學測驗中心的試題，交付之前，一定要再次確認自己有沒有合法散布這些內容的權利。

做到這裡，你應該會發現，自己一句一句跟 Codex 討論做出來的東西，跟第四模組一句話生成的成品，其實是同一件事，只是這一集讓你多練習了一次怎麼把需求講清楚。之後如果只是想快速拿到成品，不想每次都重新講一次細節，可以直接改用第四模組的捷徑。好，那第三集就先到這裡。下一集，我們會看看第四個模組怎麼用一句話，直接呼叫現成的工具，把整套流程濃縮成最短路徑。謝謝收聽，我們下一集見。
