### 工作坊簡介

AI 工具已不只是用來聊天或撰寫提示詞的工具。隨著 AI Agent 的發展，教師可以用自然語言描述自己的需求，讓 AI 協助閱讀教材、整理內容、產生題組、建立網頁，並在反覆對話與修正中完成原本看似需要程式設計才能完成的小工具。

本場工作坊將帶領教師從自己正在教授的主題、教材、講義或簡報出發，與 AI Agent 協作產生一份多題式選擇題題組，例如 10、20 或 30 題。題組包含題目、選項與正確答案；選擇題是本場的起點，目的是讓初次嘗試的教師與學生都能以清楚、低門檻的方式進入自主練習與回饋流程。

接著，教師將以 vibe coding 的方式，把題組與需求交給 AI，協作製作一個可在個人電腦開啟的靜態 HTML 自主練習小工具。學生開啟後只看得到題目與選項，作答期間不會看到答案；完成後按下送出，系統便會自動批閱，回傳答對題數、整體分數，以及每一題的對錯結果。學生也能把自己答錯的結果帶去與 AI 對話，追問錯誤原因、釐清迷思概念，再重新練習。

本場的目標不是做出一套正式考試系統，而是完成一個可實際試用的自主學習原型。教師將親手體驗：AI Agent 可以協助把教學想法轉化為工具，而未來也可以依自己的教學需求持續延伸與改良。

### 課程內容／學習重點

- 從課程主題、教材、講義或簡報整理出可練習的選擇題題組。
- 學習用「目標、情境、限制、完成標準」和 AI Agent 說清楚需求。
- 用題組與自然語言需求，以 vibe coding 產生靜態 HTML 練習小工具。
- 建立「作答前不揭示答案、送出後自動批閱」的學生使用流程。
- 讓學生以批閱結果為起點，利用 AI 釐清答錯原因與未學會的概念。
- 練習檢查 AI 產出的題目、答案與網頁功能，並以小步迭代修正。

### 預期成果

- 一份由教師自身課程內容發展的選擇題題組。
- 一個可在本機開啟的靜態 HTML 自主練習小工具。
- 一份可讓學生獲得作答結果與逐題回饋的練習流程。
- 一套可延續到其他教材、單元或教學工具的 AI Agent 協作方法。

### 重要使用說明

本場產出定位為學生課後的自主練習小工具，不作為正式成績判定或高風險測驗。學生是否真實投入練習，仍取決於其學習動機；學生也可能利用 AI 取得答案。因此，本工具的價值在於提供可反覆練習、即時回饋與觀念釐清的學習機會，而不是取代教師對正式評量的設計與判斷。
