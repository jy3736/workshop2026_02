大家好，歡迎來到 Module 3。這一集要接著 Module 2 往下一步走。前一個模組已經把考古題 PDF 處理成「一題一張乾淨圖片，加上正確答案」的問題集資料夾；現在，我們要只靠打字跟 Codex 對話，把這種資料夾變成學生可以雙擊打開、自行作答，並立刻看到分數的網頁。

先說明這一集的定位。講師其實已經事先準備好一個現成的小幫手，在 Module 4 可以用一句話請 Codex 快速完成整件事。不過 Module 3 刻意不用那個現成工具，而是從只有問題集資料夾的乾淨起點出發，自己一句一句描述想要的成果，看看 Codex 做出來的東西是否正確，再決定怎麼調整。目的不是要學寫程式，而是練習把需求講清楚，讓 AI Agent 聽得懂。完成後，你會發現這樣做出的成品，和 Module 4 用現成小幫手一句話生成的成品很類似；差別主要在製作的過程。

本教學對應 module3 資料夾。裡面目前只有兩組問題集資料夾，都是題目圖片加上正確答案，沒有任何預先做好的測驗成品。第一組是 module3/repo/115，內容是 115 學年度電機與電子群資電類的專業科目一與二，共一百題。第二組是 module3/repo/math-115a，內容是 115 學年度數學 A 共同科目，共二十五題。如果專案裡還沒有這兩組資料，可以下載 module3-repo.tar，解壓後把 repo 資料夾放進 module3。module3 底下沒有保留原始 PDF，也沒有第三組待處理資料；這是刻意保留的練習空白。

開始前，請確認你已經完成 Module 2，手上至少有一組「題目圖片加正確答案」的問題集資料夾；也已經可以開啟並使用 Codex。若工作環境還沒設定好，先回到 Module 1。這一集不需要會寫程式，不需要另外安裝軟體或套件，也不需要開啟終端機打指令。全程只要用一般的話和 Codex 對話，再用滑鼠雙擊檔案試用成果。除了 Module 2 的下載階段以外，這一整套流程都可以離線進行。

整份教學只有三件事。第一，把想要的成品講清楚。第二，自己打開來試用一次。第三，換一組新題目再試一次。用一句話說，就是：「我手上有一份題目跟正確答案，麻煩幫我做成一個學生可以自己打開作答、寫完馬上看到分數的網頁。」只要把想要什麼說清楚，怎麼做可以交給 Codex。以後每多一份新題目，例如換一個班級或一份考題，只要再說一次需求，並提醒 Codex 加進同一個工具裡，就不必從頭來過。

第一步，是跟 Codex 說清楚你要什麼。全程只靠打字對話，不用寫程式。這裡示範三種說法，從最精簡到最完整。它們都沒有程式或技術名詞；不管用哪一種當開場，Codex 都能做出堪用的成品。說得越完整，第一次做出的成果通常越貼近實際需求；即使用最短的版本，也能在完成後再請 Codex 補調整。

版本一只講最核心的需求。你可以說：「我這裡有一個資料夾 module3/repo/115，裡面是題目圖片和正確答案。麻煩幫我做一個網頁，讓學生可以自己打開來做練習題，寫完可以看到分數。這個網頁要能直接雙擊打開就能用，不需要架設網站，也不需要連網路。」其他細節交給 Codex 自己判斷。

版本二多補充學生實際使用時會遇到的畫面。你可以說，這個資料夾 module3/repo/115 裡面是一張一張的題目圖片，還有一份記錄正確答案的資料。請做一個讓學生自己打開來練習作答的網頁。學生可以自行選擇這次要練習幾題，不必每次都寫完全部題目；網頁要一題一題顯示題目圖片，讓學生選 A、B、C、D 等選項作答；全部作答完、按下送出後，馬上顯示這次考了幾分，以及每一題答對還是答錯。最後補充：這個網頁要能直接雙擊打開，不需要架設網站、不需要連網路，任何一台電腦都能直接使用。

版本三把學生從打開網頁到看到結果的每一步講得更完整。先告訴 Codex，資料夾路徑是 module3/repo/115，裡面有一張一張的題目圖片和每一題的正確答案。接著說：請做一個學生可以自己打開來練習作答的網頁。學生打開網頁後，要先輸入姓名，再選擇這次要練習幾題，從一題到全部題目都可以選。系統要隨機抽出相應題數，一題一題顯示圖片，讓學生選 A、B、C、D 等選項作答；若某一題正確答案不只一個選項，也要正確處理。全部作答完並送出後，立刻顯示分數及每一題的對錯。還要提供一個按鈕，讓學生把本次詳細結果存成能用 Excel 開啟的檔案；檔名要包含學生姓名與作答日期時間，以便保存紀錄。

在版本三最後，要特別交代兩件事。完成的網頁必須是「雙擊就能打開」的單一檔案，不需要網路，也不需要架設任何伺服器，任何一台電腦都能直接使用。另外，成品要放到新的資料夾，不要和原本的題目圖片資料夾混在一起；請 Codex 清楚告訴你成品檔案存在哪裡，以及怎麼打開來試用。這三種說法都是起點，不必逐字照抄；真正的重點是說清楚學生要看到什麼、能做什麼。

Codex 做完後，第二步是親自打開來試用。不要只信任「Codex 說做完了」。先確認資料夾中真的多了一個新的網頁檔案，直接雙擊它，不必另開瀏覽器輸入網址，看看畫面能否正常出現。接著把自己當成一位假學生：輸入姓名，選少一點的題數，例如五題，實際作答並送出，確認有出現分數，而且每一題的對錯都合理。若請 Codex 加了下載結果的功能，也要實際按一次，確認真的存出檔案，並且能直接用 Excel 開啟。如果任何一項卡住、畫面怪怪的，或出現看不懂的訊息，不用自己修改檔案，也不必猜問題在哪裡；把實際看到的狀況原原本本告訴 Codex，請它檢查並修好。

第三步是換一組新題目再做一次。module3 目前只有 repo/115 和 repo/math-115a 兩組資料，沒有預先準備第三組。這正好用來驗證請 Codex 做出的東西是否可以重複使用。你可以拿手邊任何一份考古題 PDF，或回到 Module 2，換一個感興趣的學年度或科目，重新走完下載、切題、清理的流程。完成後，將新的「題目圖片加正確答案」資料夾放到 module3/repo/新資料夾名稱，和 115 及 math-115a 同一層。

接著跟 Codex 說：「我有一組新的題目資料夾，路徑是 module3/repo/新資料夾名稱，內容跟之前那兩組一樣是題目圖片加正確答案。麻煩比照之前做的方式，幫我做出一樣的雙擊即用測驗網頁，加進同一個工具裡就好，不用整套重新做一次，也不要影響到已經做好的那幾份測驗。」完成後，再照剛才的方式試用，確認新題目正常運作，原有測驗也完全不受影響。這正好證明加新題目不必重新設計。

最後整理幾個常見狀況。若網頁打開後，題目數量比資料夾裡實際題數少，可以告訴 Codex：「我這組題目資料夾裡應該有一百題，但網頁作答時最多只能抽到比較少題，可以幫我確認是不是有題目的圖片對不起來嗎？」若雙擊成品後畫面空白或完全沒反應，就直接說看到的現象，請 Codex 檢查。若加入新題目後，原本測驗打不開或不見了，也要直接請 Codex 確認並修好。若不確定成品在哪裡，直接問：「你剛剛做出來的網頁，實際存在哪一個資料夾、檔名叫什麼？」

往後想加更多測驗，只要重複這個循環：Module 2 切題清理、跟 Codex 說一聲加入同一個工具、再打開來試用。正式交給學生前，請再次確認成品是雙擊即用、不需要伺服器、不需要網路的單一檔案。如果問題集含有可能受版權保護的考古題，例如技專校院入學測驗中心的試題，也要確認自己具有合法散布內容的權利。

做到這裡，你已經練習了如何把需求講清楚。若之後只想快速拿到成品，不想每次重新說明細節，就可以使用 Module 4 的現成小幫手捷徑。謝謝收聽。
