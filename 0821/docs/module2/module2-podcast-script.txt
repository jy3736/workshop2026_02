大家好，歡迎來到 Module 2「考古題下載、切題與清理實作教學」。這一集會帶你完成一條完整流程：把 PDF 考古題變成一題一張的乾淨圖片，再加上一份標準答案 JSON。你不需要自己寫程式；每一步都只要在 Codex 對話視窗用自然語言下指令即可完成。

本教學對應 module2 資料夾。裡面已有兩組完整跑過的範例資料，可以隨時打開，對照正確結果應該長什麼樣子。如果想跳過下載，直接練習切題，也可以下載 module2-raw.tar；解壓後會得到 raw/115 和 raw/math-115b 兩組原始 PDF。

第一組範例是 115 學年度電機與電子群資電類的專業科目一與二，共一百題。這組是從零下載示範：已下載的 PDF 在 module2/raw/115，完成切題和清理的成果在 module2/repo/115。第二組是 115 學年度數學 B，共同科目，共二十五題。這組示範 PDF 已在手上、不必下載；原始 PDF 在 module2/raw/math-115b，完成成果在 module2/repo/math-115b。

完成本模組後，你應該能用 Codex 把技專校院入學測驗中心，也就是統測，的考古題 PDF 轉成單題圖片與標準答案 JSON；理解下載、切題、清理三個階段各做什麼、為什麼要驗收，以及各自的能力邊界；理解「先乾跑，確認沒問題才正式執行」的安全習慣，特別是為什麼清理一定要先乾跑；並能自行換一個學年度或科目，獨立重跑完整流程。

開始前，請先確認你已能開啟並使用 Codex。如果工作環境還沒設定好，請先完成 Module 1 的 AI Agent 實作環境建置。步驟一的下載需要網路，因為會連到技專校院入學測驗中心網站。

本模組的三個工具都是工作坊講師預先寫好的 custom skill。每個 skill 都包含一份 SKILL.md 說明文件與對應腳本，放在這個專案的 .claude/skills 資料夾，不是 Codex 原生內建功能。和 Codex 對話時，把工作說清楚，並提醒它可以參考 .claude/skills 底下對應的工具，讓它自行閱讀說明、決定怎麼用。若它沒有主動找到，也可以直接請它開啟指定的 SKILL.md。

整個流程分成三個階段，前一個階段的輸出，就是下一個階段的輸入。第一階段是下載：輸入學年度與群類，使用 download-exam-pdf，取得 raw/學年度資料夾內的試題與標準答案 PDF。第二階段是切題：輸入第一階段的 PDF，使用 slice-exam-pdf，把每題做成 repo/名稱資料夾裡的 PNG，並建立 keys.json。第三階段是清理：輸入第二階段的 PNG，使用 clean-exam-question-images，原地覆寫成裁掉多餘空白、塗掉題號的乾淨 PNG。

兩組範例正好示範兩種起點。115 學年度電機與電子群資電類從零開始，三個階段都完成。115 數學 B 則是 PDF 已在手上，直接從步驟二開始。這是因為 download-exam-pdf 目前只認得成績單頁面的「專業科目一」與「專業科目二」列標籤，無法下載數學這類共同科目。

現在進入步驟一：下載試題與標準答案 PDF。這一步產生後續切題需要的原始 PDF。如果你已經有 PDF，例如老師自己保存的考古題，可以直接跳到步驟二。download-exam-pdf 的能力邊界是：它只認得「專業科目一」和「專業科目二」，抓不到數學 A、B、C 等共同科目。所以練共同科目時，請自行到網站下載 PDF，再從步驟二開始。

對專業科目，可以這樣請 Codex：到技專校院入學測驗中心網站，下載 115 學年度統測「電機與電子群資電類」的資料；只需要專業科目一、專業科目二的試題與兩科標準答案；下載後存到 module2/raw/115，檔名保留系統原本的命名方式。

完成後，module2/raw/115 應有四個檔案：115專業一試題.pdf、115專業一答案.pdf、115專業二試題.pdf、115專業二答案.pdf。驗收時，先確認四個檔案都出現，檔名與科目、群類相符。五十題的專業科目試題 PDF 大約十二頁，標準答案 PDF 大約一頁；頁數差太多就要留意。請 Codex 開啟下載的 PDF，再用肉眼確認群類和科目正確，不要急著進下一步。如果答案 PDF 有「答案變更為」之類的更正說明，切題時會自動將 AD 這類多重答案納入，但仍應事後對照原文，確認它確實進入答案表。

步驟二是切成單題圖片加上答案 JSON。這一步把整份 PDF 切成一題一張 PNG，並對照標準答案 PDF，產生圖片檔名對應正確答案的 JSON。

對 115 資電類範例，可以請 Codex：把 module2/raw/115 的 115 學年度試題 PDF 每題切成一張圖片，檔名使用 module2/repo/115/115專業、科目一或二、Q、題號，加上 .png；再依標準答案 PDF 建立 module2/repo/115/115keys.json。每個 key 必須與圖片檔名完全一致，包含 .png；value 放正確答案字母。

結果應包含 115專業1Q1.png 到 115專業1Q50.png、115專業2Q1.png 到 115專業2Q50.png，以及 115keys.json。例如答案表會將 115專業1Q1.png 對應到 B，115專業1Q10.png 對應到 B，115專業1Q11.png 對應到 A。

共同科目，例如數學，有兩個重點。第一，通常是二十五題，不是五十題，要先告訴 Codex 正確題數。第二，slice-exam-pdf 的輸出檔名固定包含「專業」兩字，即使科目代號是字母也不會改。所以數學 B 切完時可能得到 115專業BQ題號.png；請 Codex 改成 115數學BQ題號.png，keys.json 裡的 key 也必須同步改名。

數學 B 的指令可以明確寫成：把 module2/raw/math-115b 的 115 學年度數學 B 試題 PDF 切成一題一張圖片；這是共同科目，共二十五題，科目代號為 B；輸出檔名直接使用 115數學BQ題號.png，不要用預設的「專業」字樣；再依標準答案 PDF 建立 keys.json，key 與檔名一致且包含 .png，存到 module2/repo/math-115b。

切題後的驗收有五點。第一，圖片數量符合預期；專業科目通常五十題，共同科目通常二十五題，keys.json 的筆數也要相同。第二，如果考卷有「閱讀下文，回答第 X 到 Y 題」這類題組，挑第一題和後面一題查看，共用文章應出現，而且不可被截斷或重複貼兩次。第三，挑一題有電路圖或圖表的題目，確認圖片右邊沒被切掉。第四，查看最後一題，確認內容完整；若原題有「以下空白」，這時應仍保留，留待清理階段裁掉。第五，隨機抽兩三題，和標準答案 PDF 肉眼核對。

步驟三是清理圖片。切出的圖片下緣常多出一小段空白，甚至帶到下一題的一小段殘影；題號，例如 50 點或 11 點，也仍印在題目最前面。清理分為兩個 Pass。Pass 1 裁掉每張圖下方多餘空白，包括「以下空白」殘留，但不改動真正內容。Pass 2 塗白題號，例如 50 點、11 點，但 A、B、C、D 選項完全不能動。這兩段清理邏輯是寫給 Codex 讀取後即場執行的，因此一定要透過 Codex 對話完成。

你可以請 Codex 對 module2/repo/115 內每張 PNG 依序做兩件事：裁掉底部多餘空白，包括「以下空白」殘影，但不可裁到真正內容；清掉題號，例如 50 點、11 點，但 A、B、C、D 選項不要動。執行 Pass 2 前，必須先乾跑一次，列出每張圖偵測到的題號區塊，待確認每張都恰好抓到一個題號區塊後，才正式塗白存檔。

為什麼一定要乾跑？Pass 2 用像素座標門檻判斷題號，例如題號需從 x 小於或等於 220 的位置開始。這個門檻是針對目前考卷範本調整的。當某一年或某一科版面不同，門檻可能抓錯。乾跑只列出偵測結果，不會改動像素，因此能在正式塗白前發現異常，避免一次做壞整批圖片。

清理的驗收首先看乾跑：每個檔案都必須剛好偵測到一個題號區塊。零個代表版面與預期不同；兩個或更多代表誤判。兩種情況都要先停下來人工檢查，不可跳過。接著抽查一個個位數題號，例如 Q1，與一個兩位數題號，例如 Q50，確認題號消失且沒有半個數字殘影。再抽查至少一張有 A 到 D 選項的圖，確認選項字母都完整保留。也要抽查一張原本有「以下空白」的圖，確認空白已裁掉，內容貼近底部但仍留一點呼吸空間。最後掃描整個資料夾；若圖片底部仍有一整行與前後文無關的文字，而不是少量像素雜訊，這是切題邊界的殘影，應回頭用 slice-exam-pdf 重切那一題，不要在清理階段加規則硬修。

接著可以動手換一組資料，自己完成一次流程。基本版適合手上已有其他學年度或科目 PDF，例如自己先前下載的檔案或同事提供的檔案。直接練切題與清理，跳過下載，輸出到新資料夾，不要動到 module2 已驗證成果。例如輸出到 module2/repo/114-practice；切完後對這個新資料夾清理，並記得先乾跑。

完整版則選一個你感興趣的學年度或群類，從下載開始跑完三個階段。建議先請 Codex 用乾跑模式確認群類名稱已正確比對，再正式下載，避免白跑網路請求。無論選哪條路徑，每個階段都要完成該階段的驗收重點，不要等所有步驟做完才一次檢查。若卡住，回頭對照教學開頭的 module2/repo/115 與 module2/repo/math-115b 範例，查看正確成果的樣子。

最後整理六個常見情況。第一，如果下載 PDF 後發現群類或科目與預期不同，代表下載比對到的名稱有誤；請 Codex 開啟 PDF 肉眼核對，正確才繼續。第二，共同科目數學 A、B、C 無法用 download-exam-pdf 下載，是因為 skill 只認得專業科目一與二；請自行取得 PDF，從切題開始。第三，若切完數學題目，檔名仍有「專業」，請 Codex 改檔名並同步改 keys.json 的 key，再清理。第四，Pass 2 乾跑出現零個或兩個以上題號區塊，代表版面與範本不同或門檻誤判；先人工檢查該張圖，不能直接跳過或硬套用。第五，清理後底部仍留一整行不相關文字，是切題邊界殘影；回頭用 slice-exam-pdf 重切，不要在清理階段硬修。第六，不要把 Pass 2 的 gap 門檻從 14 調小到 10；兩位數題號，例如 11 點，兩個數字的間距可能已到十個像素。門檻維持 14，否則容易只清掉一半、留下殘影。

清理完成的圖片與 keys.json，就是後續「自主練習小工具」的原始素材。下一步可把 module2/repo/名稱這個問題集資料夾交給 build-quiz-app skill，產生不必架站、雙擊即可開啟的學生自我測驗網頁，以及教師端 CSV 彙整頁面。若想查看完成品，可參考 Module 4 的 module4/app；它使用相同流程產生測驗頁面。謝謝收聽。
